## 範圍

### 要做

**1. 國際枚舉路徑（賽事頁展開）**

- 無 Worlds/MSI 選手分類（24a 探勘已確認），枚舉走：
  歷屆 Worlds／MSI 賽事頁 → 參賽隊清單 → 隊頁 → 隊員名單（`{{TimelineSquadAuto}}`／
  Squad 模板，Wikitext 整頁留待 S25 parse）。
- 賽事頁清單來源：Liquipedia 的賽事年表（Portal 或 Navbox）逐屆列出；四大賽區
  （LCK／LPL／LEC／LCS）歷年賽段（Spring／Summer／Split）冠軍隊員。
- 選手去重：同一選手跨賽事／跨年度以 `player_id` 合併。

**2. 國際 `target_players.csv` 補段**

- 欄位同 24a 定案：`wiki_url`、`player_id`、`region`、`fetch_priority`（國際全 2）。
- 覆蓋缺口 → 照 23.7 三級備援判定，逐筆標 `data_source`。

**3. 國際隊 `team_history.json` 補段**

- 國際隊（T1、DRX、Gen.G、RNG、Fnatic、G2…）的 `team_id`／`display_name`／
  `region`／`active_years`；更名隊（SKT → T1 等）標 predecessors／successors。
- 與台港澳段同一份檔，S23 schema 是權威。

### 不要做

- **不抓國際 raw**（S24d 的活）——本站只列清單與枚舉器
- **不解析、不清洗**
- **不呼叫 LLM**
- 不碰 `src/` 與 `tests/`
- 不抓選手真實姓名（§23.1）
