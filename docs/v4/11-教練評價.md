## 為什麼做這件事

V4 §10 廢掉 OVR，但不是把它刪掉——是把它拆成兩層：

- **顯性層**：玩家看到十二項技能（0–100），本位置核心技能標註。玩家知道練哪些屬性
  可以拉高目標技能
- **教練評價（內部值，不顯示）**：處理薪資、試訓、續約、FA 報價這些「需要單一數值」
  的場合

```
教練評價 = Σ(位置相關技能 × 位置權重) + 隱藏心理修正 + 特質調整
```

跟現行 `effectiveOvr` 的差別有兩處：**多了心理修正項**，而且**不再顯示給玩家**。
心理掛進教練評價是刻意的——讓「看不見的心理素質」間接影響薪資與續約（教練看得出的
態度與大賽心態）。

**4. 實作明星效應（V4 §11.1）**

```
玩家位置戰力 P = Σ(位置相關技能 × 權重) × 心理穩定修正 × 版本適應修正
團隊強度 = P × 0.60 + 隊友均值 × 0.40 + 教練加成 + 體力修正 + 特質
```

兩處要改 `src/kernel/strength.js`：
- 玩家權重 0.55 → **0.60**（隊友 0.35 → 0.40，教練與體力另計）
- **加上明星效應的超線性項**，函數形式依 S08 洞 7 定的（起點是
  `max(0, P − par)^1.35` 那類）

「體力修正」這一項現在讀 `skillValue(state,'sta')`，S10 已改成暫時來源，
維持 `TODO(S13)` 不動。

## 規則與不變式

S07 不變式全綠。這一站特別要盯的：

- **薪資與晉級不能整組錯位。** 檢查方法：160 段生涯裡「打進主流賽區的比例」與
  「平均生涯薪資」跟 S10 的水準相當。抄進交接筆記
- **明星效應不能讓 w_p=0.60 失效。** 強玩家在弱隊要能拉抬勝率但不能一個人打贏整隊。
  檢查方法：找出樣本裡玩家戰力遠高於隊友的那幾段，看勝率有沒有失控（例如 >0.92 的
  上限被頂滿）
- **教練評價不得出現在玩家可見的養成介面**
