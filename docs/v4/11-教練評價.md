理由：31 處 `.ovr` 引用的改名是機械的，但**聯賽 par／薪資曲線／隊友強度區間的重校

## 為什麼做這件事

V4 §10 廢掉 OVR，但不是把它刪掉——是把它拆成兩層：

- **顯性層**：玩家看到十二項技能（0–100），本位置核心技能標註。玩家知道練哪些屬性
  可以拉高目標技能
- **教練評價（內部值，不顯示）**：處理薪資、試訓、續約、FA 報價這些「需要單一數值」
  的場合

```
教練評價 = Σ(位置相關技能 × 位置權重) + 隱藏心理修正 + 特質調整
```

跟現行 `effectiveOvr` 的差別有兩處：**多了心理修正項**，而且**不再顯示給玩家**。
心理掛進教練評價是刻意的——讓「看不見的心理素質」間接影響薪資與續約（教練看得出的
態度與大賽心態）。

## 交接筆記

### 一、⚠ 先讀這一節：§11.1 的權重改動不是「加重玩家份量」而已，它把整個難度往上推了 5 點

說明書預期這一站的平衡工作是「心理修正加進來之後分布形狀的變化」。**心理修正這一站是
0（等 S12），真正的地雷在別的地方**：

`w_p` 0.55 → 0.60 看起來只是玩家份量多五個百分點，但舊的兩個權重**加起來只有 0.90**
——在 par 66 時等於把整隊強度系統性壓低 6.6 點，再由教練與體力那 ~5 點補回來，淨值約
`par − 1.1`。§11.1 的新權重和是 **1.00**，教練與體力變成純加項（它的驗算例明寫
「教練/體力 3.5」疊在 0.60/0.40 之上），所以同一支隊的強度直接上移約 5 點。

照字面實作跑 160 段的後果：

| 指標 | S10 | 照字面實作 §11.1 |
| --- | --- | --- |
| 有國際賽冠軍當量的生涯 | 39 段 | **84 段** |
| `五個等第都出現得到` | 綠 | **紅**（邊緣選手 0 段——沒有人再打得爛） |
| 能把單局勝率頂到 92% 的生涯（4 組種子） | 1／640 | **18／640** |

**不是實作錯了。** §11.1 的驗算例（P=100、隊友 59、對世界賽淘汰賽 78）在這份程式上算出
團隊強度 94.1、單局 72%，跟規格書寫的 93.1／76% 對得上；明星項的分段對照表七個點
**一個數字不差**（0.53／0.99／1.34／2.32／3.42／4.63／6.0，已寫成不變式）。是規格書的
驗算只查了一半。

### 二、修法：`OPPONENT_SUPPORT`——這是本站唯一新增的常數，也是唯一需要有人反對的決定

根因是一個**單位錯位**，舊制的 0.90 權重和剛好把它遮住了：

- §11.1 的對手強度階梯（`par`／`par+2`／`max(par,74)+…`）是 **`par` 系**的數字，而 `par`
  的定義是「該聯賽**先發平均教練評價**」——那是**一個選手**的水準。
- 我們這邊的 `teamStrength` 是**一支隊**的強度（含教練、體力、明星項）。
- 直接相減 ＝ 讓對面用一個選手打我們一支隊。

所以 `kernel/strength.js` 新增 `OPPONENT_SUPPORT = 6.5` 與 `opponentStrength()`，**所有拿
階梯值當對手的地方都要走它**（常規賽 `season.js`、季後賽 `series.js`、Swiss `groups.js`、
MSI／世界賽的 `intlOpponent`，共五處）。值有兩份互相印證的來源：

1. **推導**：對手也是一支隊 → 教練/體力 3.5（§11.1 驗算例自己寫的）＋ 它自己的明星項
   約 3.0（階梯上的隊伍是賽區冠軍等級，carry 高出 par 約 15–20 點，查 §11.1 分段表是
   2.3–3.4）＝ 6.5。
2. **實測**：掃 3.5／5／6.5／8 跑 640 段，**只有 6.5 把 S10 的校準整組帶回來**
   （世界冠軍人均 0.11 對 S10 的 0.098、有冠生涯 122 對 125 段、平均薪資 −1%）。
   3.5 會讓世界冠軍人均翻成兩倍。

**這是本站對 §17.2「不要各自發明」的唯一一次偏離**，理由是鐵則一：測試網是平衡的權威，
而照字面實作會讓 `五個等第` 翻紅。要反對的話回退方式是把常數改成 3.5，然後接受上表那三
個後果——**但請不要只把它刪掉**，刪掉等於回到「拿一個選手比一支隊」，實測會直接紅。
S22 文件同步時應該把這一項補回 §11.1／§17.2。

### 四、教練評價與位置戰力是**兩個量**，S12 要各接各的

`engine/attributes.js` 現在有三個出口，不要混用：

| 函式 | 內容 | 誰讀 |
| --- | --- | --- |
| `coachRating` | 位置加權技能 ＋ 隱藏心理修正 ＋ §10.2 特質調整 | 薪資／試訓／續約／FA／板凳／獎項／生涯評分 |
| `effectiveCoachRating` | 上面 ＋ 版本落差 | 市場那一整排（跟不上版本，估價就掉） |
| `positionPower` | 位置加權技能 × 心理穩定修正 ＋ 版本落差 | 只有 `teamStrength` |

**`positionPower` 刻意不吃 §10.2 的加法特質**（神之領域 +2、不老傳奇 +1）：那是「教練
怎麼看你」，不是「你在場上打得出多少」。已寫成不變式，故意讓它吃會紅。

心理的兩條出口寫在同一個 `TODO(S12)` 註解塊裡（所以 grep 只有一處），**S12 請不要把它們
合成一條**：§10.2 的隱藏心理修正是**加法 ±3、只吃 drive/disc/comp、進教練評價**；§11.1 的
心理穩定修正是**乘法、進位置戰力**。合成一條的話一次崩盤會同時砍掉戰力與身價，那是兩次
懲罰，而 §10.2 明講信任與韌性是隊內的事、自信是場上的事，都不該由教練的報價來表達。

⚠ **S12 接上 ±3 之後，`invariants.mjs` 的 `巔峰上界` 母數要跟著加 3**（現在只算了
`RATING_TRAIT_HEADROOM`）。註解已經寫在那條檢查上面。
