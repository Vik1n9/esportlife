# 「電競人生：LoL 職業選手生涯模擬」改造計劃書（v2.1 修訂版）

- 將單檔 HTML 棒球生涯模擬 `yakyulife/index.html`（v1.3.3）改造成 LoL 電競生涯模擬，保留核心引擎（種子 RNG、20–80 量表、三階段季循環、事件卡、合約/轉會、分享圖）。
- **預設從 S2（2012）開始**、年齡 16；**中度史實演進**：主場聯賽 GPL→LMS→PCS→LCP、MSI（2015+）、世界賽格式（2023+ Swiss）、薪資規模隨時代調整。
- **老將長壽機制**：對照 Faker 型頂級選手可打到 30+；衰退曲線由年齡＋特質決定，基礎退役硬上限 34。
- **特質合成（完全隱藏）**：多個基礎特質同時持有時自動合併成史詩特質。
- **歷史解散與改寫**：真實在該年解散的隊伍，若玩家在隊且未帶隊奪世界冠，季末強制解散進入自由市場；自由市場不達標者強迫退休結算。
- 使用**真實戰隊名**與英雄名；版本升至 **v2.0.0**；產出 `ESPORT-DESIGN.md` 並更新 README／CHANGELOG／WIKI。

## 二、時代演進與生涯時間軸

- `startYear=2012`、`startAge=16`；每季＝一真實年；`ERA(year)` 回傳時代旗標：
  - **草創（2012–2014）**：主場 `GPL`；無 MSI；世界賽 16 隊小組→淘汰；薪資 ×0.35；海外僅 NA/EU（2013+）與 KR/CN。
  - **成熟（2015–2019）**：主場 `LMS`；MSI 開辦；LPL/LCK 獨大；薪資 ×0.7；2017 起世界賽加入圍賽。
  - **全球化（2020–2024）**：主場 `PCS`；薪資 ×1.0；2023 起世界賽改 Swiss。
  - **現代（2025+）**：主場 `LCP`、LTA 成立；薪資 ×1.2；世界賽 Swiss。
- 生涯階梯：`校園 → 青訓次級 → 主場聯賽 → 海外頂級賽區(LCK/LPL/LEC/LCS) → MSI／世界賽`；`LV` 依時代帶入主場聯賽名與 `par/min/g`（現代基準：校園 34、次級 44、主場 53、海外 56–61）。
- **年齡與衰退**：`ref/op/sta` 26 起緩降、30 加速、33 陡降；`macro/lead/vis` 隨經驗續升至約 35；基礎硬上限 34，可被特質延後。

## 三、歷史解散與強制職業生涯終結（新增）

- **解散事件表** `DISBAND={year:{team:{n,note}}}`（可擴充），決策完整範例：
  - 2016 `台北暗殺星`（TPA 改制）；2019 `閃電狼`（FW 退出聯賽）與 `MAD Team`；2021 `ahq 電子競技俱樂部`（LoL 分部解散）；並可擴充海外知名解散（NA/EU 各年退出者）。
- **觸發規則**：
  1. 季初若玩家隊伍在當年解散表內 → 設季節旗標 `disbandThreat`（敘事卡暗示「母公司財務問題流言」）。
  2. **改寫史實**：該季若玩家所屬隊**贏下世界賽冠軍**，解散被避免（`disbandAverted`）→「你們用世界冠軍贖回了俱樂部」事件，該年解散項移除，回到正常續約流程。
  3. **未建立**：季末休賽期觸發「**隊伍解散**」事件 → **強制進入自由市場**（`forcedFA`，跳過正常續約/留隊流程，玩家無法留原隊）。
- **自由市場強迫退休**：FA 評估以「OVR、該季表現係數 `perf`、年齡、傷病史」對目標賽區 `LV.min` 門檻；若**無任何合格報價**（OVR 或表現不達標／連續兩年未達），立即進入**強迫退休結算**（`forcedRetire=true`，即使年輕也走退役/生涯結算流程，含敘事「功勳老將在解散後無人接手，黯然退役」）。
- 與特質/長壽機制互動：`不老傳奇`等延長能力但**不保證簽約**——高 OVR 者仍會獲邀；若衰退＋解散導致無隊要，仍會強迫退休。`神主牌/更衣室傳奇`可提高留隊/續約優先。

## 四、核心系統

- **能力值**：共同（`sta 體力, ref 反應, op 操作, macro 大局觀, lane 對線, tf 團戰, roam 遊走, vis 視野`）；位置專屬（`TOP→單帶, JG→節奏, MID→刺客, ADC→輸出, SUP→開戰`）；`ROLE_N` 五路、上限 80、潛力天花板與成本沿用；新增位置加權 `ovrRole()`。
- **英雄池與版本**：每路 8 隻真實英雄池（決策名單見前版）；專精隨出賽成長；`版本大改動`重排 Meta，`版本適應`＋池廣度決定 `seasonFactor`。
- **比賽模擬**：逐場 `K/D/A、KDA、CS、VISION、DMG%、SOLO、MVP`；勝負＝團隊 OVR（玩家＋4 隊友＋教練）vs 對手＋隨機；季循環＝訓練期→賽季→季後賽＋世界賽資格→休賽期。
- **國際賽**：MSI（2015+，強制/婉拒徵召沿用，冠軍隊為賽區爭世界賽名額）；世界賽 Play-In→Swiss→八強單敗→FMVP。
- **隊友/教練/轉會**：每隊＝玩家＋4 虛構名隊友＋教練體系標籤；休賽期轉會市場（續約/轉會海外含語言文化事件/FA/拒絕）；`faFlow`/`handleDemotion` 改名沿用，並與上節解散/強迫退休流程接軌。
