# S33 · 微觀數據與排行榜（Phase 2）

狀態：未開始
前置：S32
預估：1 session
推理難度：中
建議模型：Sonnet 5（`claude-sonnet-5`）
理由：公式與方差級距由 S31 定案，本站照做。判斷點在分佈的真實感驗證——
量 KDA／DPM 的聯賽分佈像不像真實聯賽，不新做設計決定。

---

## 為什麼做這件事

S32 只有勝負與局數，還撐不起「聯賽數據」：§24.3 的動態評價基準、任務卡與
合成的百分位謂詞全部要吃微觀數據。本站把單局詳細數據（K／D／A、DPM、分均
補刀、視野分數）生成出來，並建聯賽積分榜與個人數據榜。

---

## 入口狀態

```bash
node docs/v4/next-station.mjs
```

回報本站為下一站。S31 定案：微觀公式、位置權重、tec／agi／awr 綁定係數、
三種局（碾壓／均勢／爆冷）的方差級距。S32 的宏觀模擬與資料池就位。

---

## 範圍

### 要做

**1. 微觀數據生成模型**

- 照 S31 公式：擊殺、死亡、助攻、分均傷害、分均補刀、視野分數，綁定位置
  權重與六維屬性（tec→輸出、agi→死亡修正、awr→視野）。
- 常態分佈方差依局型（碾壓／均勢／爆冷）套用 S31 的級距。
- 與宏觀結果一致：勝隊的微觀分佈要符合勝負關係（不可出現「勝隊全員數據
  慘敗」的系統性矛盾，除非 S31 定案刻意保留）。

**2. 排行榜實作**

- 聯賽積分榜（S32 已有宏觀部分，本站補完）＋個人數據榜（KDA 榜、DPM 榜、
  視野榜，按位置分列）。
- 榜單的快照機制：依 S31 定案（快照 vs 重算）落地。

**3. 分佈驗證**

- 160 段（或 S31 定案的驗證母體）抽驗：KDA 均值與方差落在真實聯賽量級
  （S31 定案的驗收區間），爆冷局比例符合預期。
- 量測結果寫進交接筆記，供 S34 的動態基準與 S36 的校準使用。

### 不要做

- 不碰玩家數據接入（S34）——玩家數據照舊從 `season.js` 產，尚未併池
- 不做國際賽獨立榜（S35）
- 不推翻 S31 的公式；公式錯了改腳本，規則錯了寫交接筆記
