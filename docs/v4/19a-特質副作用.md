## 為什麼做這件事

V4 §13.1：**每個特質＝益處＋副作用。越強的特質副作用越大。無純正面特質，
取得本身就是取捨。**

現行 50 個特質（26 通用 / 8 稀有 / 10 史詩 / 6 傳說）**幾乎都是純益處**。
`鐵人`（受傷機率大幅降低）、`天才操作`（訓練骰固定 4 點以上）拿到就是純賺。
少數有代價的（`肝帝` 練得多也傷得多）是例外不是通例。

V4 §13.3 的三層約束（每項自帶副作用／互斥組／合成消耗＋跨配方共用元件）裡，
**第一層完全沒做**。這一站補它，順便補互斥組與維持條件。

## 範圍

### 要做

**必讀規格**：V4 §13（特質系統全節）、§9（心理六維，副作用可以掛在這裡）、
§11.2（院長特質的示例——那是 PoE 式雙面性的範本）。

**必讀既有實作**：`src/kernel/modifiers.js` 的四種效果寫法
（加法／`mul`／`floor`／`cap`／旗標）。副作用用同一套機制表達，不需要新架構。

**1. 每個特質補副作用，依 §13.2 三級**

| 級別 | 強度 | 典型形式 | 掛載對象 |
| --- | --- | --- | --- |
| 輕度 | 小數值扣減 | −少量屬性、輕微情境不利 | 一般基礎特質 |
| 中度 | 明顯扣減 | 屬性下降、技能成功率降、鎖定某訓練 | 高價值基礎特質 |
| 重度 | 大幅扣減、改變玩法 | 禁用某路線、提高受傷/心態崩盤機率 | 史詩特質、強力特質 |

原則：**益處越強，副作用級別越高。** 史詩特質可保留一個重度副作用作為代價。

50 個特質都要補。副作用要**跟益處有主題關聯**——`天才操作`（訓練效率高）的副作用
應該是「疏於基本功」那類，不是隨便扣一個無關的數值。V4 §11.2 的院長特質是範本：

| | 內容 |
| --- | --- |
| 正面 | 個人數據加成、人氣上升、關鍵局單 carry 機率提升 |
| 副作用 | 隊友戰力折減、默契/信任下降、更難觸發團隊系特質 |
| 副作用可消除 | 搭配「團隊領袖」抵銷隊友折減 → build 組合 |

**最後那條很重要**：某些副作用可以被另一個特質抵銷，形成 build 組合。
這是隱藏探索的一部分——至少要做出 3~5 組這種抵銷關係。

**2. 互斥組（§13.3 第二層）**

部分特質無法共存，取得其一鎖掉整條路線。標在特質資料上，`kernel/modifiers.js`
要能查。

**3. 維持條件（§14.2）**

> 特質同時也有維持條件，舉例一直保持單身的單身特質，一但交往就會失去該特質。

現行 `singleYears`／`romance` 已經在 state 裡，但失去特質的機制沒有。
補上：特質可以宣告 `maintain(state)`，不成立時失去。

⚠ **失去特質要有敘事**。默默消失玩家不會知道發生什麼事。

**4. 效果從 OVR 改掛新體系（§14.2）**

> 特質效果掛新多維體系（技能/心理/失誤），不再掛 OVR（OVR已廢除）。

S11 已經把 `ovrAdd` 那類鍵改名。這一站進一步：能掛在**技能**、**心理**、**失誤率**
上的就掛過去，不要全部堆在教練評價上。

**5. 整理 `phases/shared.js` 裡硬寫的特質解鎖**

現行 `drawEvent` 有一串 `if (flags.popular && unlockTrait(state, 'popular'))`
（十來行）。S17 刻意沒動它，這一站把它資料化——`flags` 的鍵直接對應特質鍵，
不必一條一條寫 if。

### 不要做

- **不要新增特質。** 傳說 6→20 是 S19b，這一站只補既有 50 個的副作用
- **不要改配方表**（S19c）
- **不要改 `kernel/modifiers.js` 的四種寫法。** 用既有機制表達副作用
- **不要讓副作用強到把特質變成負資產。** §13.1 說的是取捨，不是懲罰
- **不要碰扮演卡**（S20）

## 規則與不變式

- S07 不變式全綠。**副作用會壓低整體強度**，跑完看巔峰有沒有掉太多
- **每個特質都有副作用**：寫一個測試掃過四階特質表，沒有副作用欄位的就紅
- **互斥組要對稱**：A 與 B 互斥，B 也要與 A 互斥
- **抵銷關係至少 3 組**，並在測試裡驗證抵銷真的生效
- **維持條件失效要有敘事 beat**
