## 為什麼做這件事

V4 §14.2 只寫了「配方需要重製」，是個空的。

現行 24 條配方是為舊體系設計的（掛 OVR、沒有副作用、素材是舊的 26 通用特質）。
S19a 補了副作用、S19b 把傳說擴到 20——配方必須跟著重做，否則 14 個新傳說沒有任何
取得途徑。

V4 §14.1 的合成規則：

- 通用 → 稀有、通用 → 史詩（**兩池不重疊，不是嚴格階梯**）
- 取得特質後**自動檢查配方，命中即合成**（**僅限稀有與史詩兩階**）
- 合成後**低一階的會被消耗掉**
- 被消耗的低階特質**不可再取**
- UI 不揭露配方，僅氛圍敘事，玩家靠 WIKI/社群探索

V4 §13.3 第三層約束：**跨配方共用元件**——低階特質是多條高階配方的共同材料，
合成消耗後不可再取 → 選一條就鎖掉其他。這是 build 分歧的來源。

## v4.1 之後這一站分成兩件事

**傳說已經不是配方了**（§13.4：唯一來源是生涯任務卡達成）。所以這一站的範圍變成：

| 前半：配方 | 後半：門檻校準 |
| --- | --- |
| 重製稀有（8 條）與史詩（10 條）配方 | 校準 25 張生涯任務卡的**達成目標數值與期限** |
| 素材分兩池、稀缺優先、死配方規則 | 讓持有率落回 §14.2 的驗收表 |
| 產出在 `src/data/epics.js` 的 `FUSIONS` | 產出在 `src/data/quests.js` 的數值欄位 |

後半是新的，而且是**這一站真正的判斷成本所在**——傳說持有率現在由「任務卡開得出來
的機率 × 達成得了的機率」決定，兩個旋鈕而不是一個。前置多了 S18，因為要有 25 張真卡
才校準得了（S17b 放的是假卡）。

## 範圍

### 要做

**必讀規格**：V4 §14（特質合成全節）、§13.3（三層約束）。

**用 S18a 的編輯器**：<http://localhost:8080/tools/> 的配方頁會即時檢查
**素材分池不重疊**——那正是這一站最容易踩的坑。

**1. ⚠ 先讀踩過的坑**

`docs/superpowers/specs/2026-08-12-four-tier-trait-synthesis.md` 記錄：

> 第一版把「稀有 → 史詩」做成嚴格階梯（2 稀有 → 1 史詩、史詩再往上疊），結果 160 段
> 生涯的史詩持有率從基準 71/80 掉到 10/80、平均巔峰 OVR 從 60.5 掉到 57.5——因為稀有
> 配方跟史詩配方**搶同一批稀缺的通用素材**，稀有先檢核就把史詩的素材吃光了。
>
> 修正：稀有吃「人格／媒體」類通用，史詩吃「競技表現」類通用，**兩池不重疊**。
> 如此稀有與史詩能同時成立、互不搶素材；傳說＝史詩＋稀有，素材必然分屬兩池。

實測基準（160 段）：

| 指標 | 值 |
| --- | --- |
| 平均巔峰 OVR | 59.9 |
| 史詩持有率 | 63/80 |
| 稀有持有率 | 69/80 |
| 傳說持有率 | 23/80 |

**分池原則要沿用。** S08 在規格書 §14.2 定的配方表應該已經標明素材分池——照它做。
若沒標，停下來寫進交接筆記。

**2. 配方由編輯器定義，本站驗收＋供給重推（v4.3 改）**

v4.3 起配方內容由特質編輯器（S18a）定義，本站**不重寫 FUSIONS 內容**，而是：

- **驗收**：編輯器產出的配方過兩條衛生規則（死配方取得率 ≥15%、同池撞素材取取得率
  乘積最低者），分池不重疊。
- **移除傳說配方**：`FUSIONS` 裡若有 `outTier === 'legendary'`（如舊的 `immortal`，
  `epics.js:151`），移除——傳說唯一來源是任務卡，留著就是第二條發放路徑。
- **重推供給算式**：照編輯器重定義後的配方形狀，重推「每個史詩進幾條、稀有依取得率
  分配幾次」的配額。

現有的資料結構已支援跨階素材（`need: [[tier, key], ...]`，`checkFusions`），
**不必改架構**，只改配方內容的來源（從手寫變編輯器產出）。

⚠ **S19d 把天生特質也加進了通用池**，兩個素材池的取得率會整批往上跑。開工第一件事
是重量一次素材取得率（S19d 的交接筆記有一份），**稀缺優先規則要照新的取得率重排**，
不是照 §14.2 表上那份舊實測值。

**3. 跨配方共用元件（§13.3 第三層）**

刻意讓某些低階特質同時是多條配方的材料。玩家選了一條就鎖掉其他——這是 build 分歧
的機制來源。

⚠ 但**共用不能造成搶素材**（那是上面那個坑）。安全的做法：**池內共用，跨池不共用**。
同一池裡的配方可以搶同一個素材（那是取捨），但稀有池與史詩池之間絕不重疊。

**4. 校準 25 張生涯任務卡（v4.1 的後半站）**

傳說持有率現在由**兩個旋鈕**相乘決定：卡開得出來的機率 × 期限內達成的機率。

- **開卡率**由觸發條件決定：底線門檻（國際賽四強以上）實測聯合命中率 30.0%（§14.2），
  這是**上界**——20 張卡各自還要滿足自己的條件式。

⚠ **開工第一件事是翻 S18 的交接筆記，看有哪幾張卡改了觸發條件的形狀。** §14.2 那張表
是校準用的預設配置，S18 可以把某張改成「兩個稀有」或「賽事成績 ＋ 一個稀有」（V4 §12.3
給的設計自由）。表下面的配額推導（每個史詩恰好進兩條、稀有依取得率分配次數）**只在
「每張卡一史詩一稀有」時成立**，形狀變了就要重推供給算式——否則你會拿一份對不上的
素材面預算去校準達成率，兩個旋鈕一起錯。
- **達成率**由每張卡的達成目標與期限決定，這一站要定的就是這些數值。

驗收線（V4 §14.2 目標持有率表）：

| 指標 | 目標 | 性質 |
| --- | --- | --- |
| 稀有 ≥1 | 50–60%（S19d 之後要重訂） | 軟 |
| 史詩 ≥1 | 55–65% | 軟 |
| 傳說 ≥1 | **28–35%** | 軟 |
| 傳說 ≥1 | **≤50%** | **S07 硬上限，不准放寬** |
| 傳說 ≥3（單局） | **≤5%** | 管疊加，§12.3 允許單局多個傳說 |
| `route` 標籤 ≥1（後段局） | **≥60%** | 心流檢驗，§14.3 |

最後一條是這一站唯一**要往上推**的指標。它與傳說的 ≤50% 不衝突：`route` 發的是史詩
＋標籤，不是傳說（§14.3）。若量出來的 `route` 覆蓋率不足，先放寬 `route` 卡的條件，
**不要改成發傳說**。

**同時要校準 §14.3 兩條路線的絕對門檻**：「究極綠葉」的生涯場均助攻門檻與「網紅選手」
的 `careerScore < 900` 那條線。數值的依據是 S17a 交接筆記量到的帳本分布，不是拍腦袋。

**5. 「合成後低階不可再取」的驗證**

`state.fusedAway` 機制已經存在（`src/engine/progression.js`）。稀有／史詩配方重寫之後
要確認它仍然成立——被消耗的特質不會被事件卡重新解鎖。

⚠ v4.1 多了一個路徑要驗：`legend` 任務卡的素材是**達成時才消耗**（S17b 定案），
所以「開卡了但逾期失敗」的生涯，那組史詩＋稀有必須仍在 `state` 裡、沒有進 `fusedAway`。

**6. UI 不揭露配方（§14.1）**

確認 `src/ui/panel.js`／`src/ui/summary.js` 沒有任何地方列出配方。
合成發生時只給氛圍敘事（`fusionBeats` 已經是這樣做的）。

## 規則與不變式

S07 不變式全綠。這一站是**整條線最容易破壞平衡的地方**，四項都要盯：

- 老手打法：傳奇不得超過三成
- 新手打法：傳奇要罕見（不到老手的三分之一）
- 老手平均巔峰至少高 1.5
- 五個等第都出現得到

加上持有率驗收——**以上面「校準 25 張生涯任務卡」那張表為準**。四階合成那份 spec 記的
69/80、63/80、23/80 與現況對不上（量的批次不同），V4 §14.2 已註明以規格書的表為準。

**分池不重疊**要做成測試：掃過所有配方，稀有配方的素材集合與史詩配方的素材集合
交集為空。

**傳說不在 `FUSIONS` 裡**也要做成測試：`FUSIONS` 掃過去不該有任何 `outTier === 'legendary'`
的條目——那是 v4.1 唯一會讓傳說繞過任務卡的漏洞。

### 重校決策（規格書 #57）

28–35%／≤5% 是舊配方時代（#28）的驗收線，任務卡體系（#30）下**不可同達**：

1. 20 張傳說的達成目標全部吃強生涯成就（awards／splitTitles／國際賽軌跡）→ 達成段與
   頂端段高度重合（實測：達成段的持有分佈 5+ 張/段有 12 段，0 張的段 132 段）。
2. 提高 ≥1 需要「開卡即達成」的底線卡（S19c 實驗：godslayer 改戰績型後 ≥1 從 11.9%→
   18.8%），但底線卡同時加劇頂端段疊加 → ≥3 爆線。
3. 互斥網（§13.3 第二層）補不了：引擎語義是「先達成擋後達成」——底線卡永遠先達成，
   把招牌卡永久鎖死（實測：godslayer↔worlds_king/goat 互斥時 worlds_king、goat 特質
   0 發放，任務照算達成）。實測後全數撤回。

最終 17.5%／11.9% 是張力下的平衡點。
