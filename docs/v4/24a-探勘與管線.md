## 探勘前置知識（2026-08-16 已實測，不必重探）

> 這些是上一輪研究 session 實測的結論，直接當既定事實用。若與實測不符，以實測為準
> 並在交接筆記更正。

### 技術路徑（全部走 MediaWiki API）

- 端點：`https://liquipedia.net/leagueoflegends/api.php`。**gzip 必需**——漏掉
  Accept-Encoding 回 406「Gzip encoding is required」（curl 加 `--compressed`）。
- UA 必含工具名＋聯絡方式（如 `LiquipediaDataBot/1.0 (…; mailto:…)`），否則 403。
- **使用條款（/api-terms-of-use）明文**：
  - 只准 API 自動化，**禁止自動化存取非 API 的 HTML 頁面**——不能爬 Category 網頁版
  - 重用／快取 API 結果，不做重複請求
  - CC BY-SA 3.0 出處註記（§23.3 標頭格式已含）
  - ⚠ 說明書曾寫「UA 輪替」，與政策（固定識別）衝突——**採固定識別 UA**，
    不輪替。違反政策會整個 IP 被擋。
- ⚠ LoL wiki **無 Cargo 擴充**：`action=cargoquery` 與 `Special:CargoExport` 都回
  「No such special page」——Squad 資料無法 SQL 查，只能抓頁面 Wikitext parse。

### 枚舉入口（抓取清單的來源）

| 目的 | 分類／頁面 | 實測 |
| --- | --- | --- |
| 台港澳選手全量 | `Category:Taiwanese Players`／`Hong Kong Players`／`Macau Players` | 齊全（HK 有 1xn、AmazingJ、Dennis 等；Macau 4 筆） |
| 台港澳隊 | `Category:Taiwanese Teams`＋`PCS Teams`＋`LCP Teams` | 齊全（Ahq、FW、J Team、Machi、CTBC、PSG…） |
| 國際選手 | **無 Worlds/MSI 選手分類**——只能由賽事頁展開：賽事頁 → 參賽隊 → 隊頁 → 隊員 | 路徑可達，S24c 建完整枚舉 |
| LMS 時代 | LMS 隊伍多掛 Taiwanese Teams（無 LMS 分類） | Flash Wolves 等都在 |

### 頁面結構

- **選手頁**：`Infobox player` 有 `birth_date`／`country`／`roles`／`history`／`ids`
  （別名）。⚠ `name` 欄是**真實姓名**（如 Maple 頁 `name=黃熠棠`）——清洗時忽略，
  不進資料。頁題常是消歧義後綴＋REDIRECT（`Maple` → `Maple_(Taiwanese_player)`）。
- **隊頁**：`Infobox team` 有 `region`／`created`／`disbanded`；History 段記更名前身
  （如 Flash Wolves「founded as yoe IRONMEN」）——predecessors 來源之一。
- **賽事頁**：`Garena Premier League/2014/Spring` 模式（斜線路徑），`Infobox league`
  有 `series`／`team_number`／`sdate`／`edate`。GPL 2012 有 `Opening Event` 頁——
  早期覆蓋比預期好，但 2012–2013 逐年度仍要實測（23.7 點名最薄處）。
- **隊員名單**：隊頁與賽事頁用 `{{TimelineSquadAuto}}`／`{{Squad…}}` 模板——S24 抓
  整頁 Wikitext 即可，parse 是 S25 的事。

## 範圍

### 要做

**1. 完整探勘（產出覆蓋表，寫進交接筆記）**

- 逐年覆蓋表：GPL（2012–2014）／LMS（2015–2018）／PCS（2019–2024）／LCP（2025）
  各年賽事頁存在性、隊與選手分類覆蓋——23.7 的「賽區 × 年份 × source」實測表。
- 國際枚舉路徑驗證：挑 2–3 屆 Worlds／MSI 賽事頁，確認「賽事頁 → 參賽隊 → 隊頁 →
  隊員」鏈路可達（完整枚舉是 S24c）。
- 隊頁更名結構：抓 Flash Wolves／J Team／G-Rex／Machi 等，確認 predecessors／
  successors 的可靠來源（Infobox＋History 段？頁面重定向？）。
- 探勘結論含：備援動用幾處（23.7 觸發條件任一成立才動 Leaguepedia）。

**2. `crawl.mjs` 基建**（`tools/npc/`，零相依）

- API 客戶端：gzip（Node 內建 fetch 自動處理）、固定識別 UA、2–5s 隨機延遲、
  退避重試（429／5xx）、404／REDIRECT 記錄。
- 枚舉子命令：吃分類／賽事頁清單 → 產出目標 URL 集合。
- 抓取子命令：批次 50–100，中斷續傳（已抓檔案存在即跳過，manifest 記錄成功），
  冪等——重跑完全跳過已下載。
- raw 落檔：`raw_data/<slug>.wiki`，整頁 Wikitext，**不做任何解析**。
- 資料檔標頭 CC BY-SA 註記格式（§23.3 已定）。

**3. `tools/npc/README.md`**

- 使用方式、續傳指令、重新下載方式、政策要點（gzip／UA／rate limit）。

### 不要做

- **不解析、不清洗** raw_data（S25 的活）
- **不列國際清單**（S24c）、**不抓台港澳 raw 全量**（S24b）——本站只管基建與探勘
- **不呼叫 LLM**
- **不要「順便修正史實」**（S05 同款）：發現 Liquipedia 資料可疑寫進交接筆記，本站不改
- 不碰 `src/` 與 `tests/`
- 不推翻 §23.1 四件定案
