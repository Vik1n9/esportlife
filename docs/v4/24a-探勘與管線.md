### 技術路徑（全部走 MediaWiki API）

- 端點：`https://liquipedia.net/leagueoflegends/api.php`。**gzip 必需**——漏掉
  Accept-Encoding 回 406「Gzip encoding is required」（curl 加 `--compressed`）。
- UA 必含工具名＋聯絡方式（如 `LiquipediaDataBot/1.0 (…; mailto:…)`），否則 403。
- **使用條款（/api-terms-of-use）明文**：
  - 只准 API 自動化，**禁止自動化存取非 API 的 HTML 頁面**——不能爬 Category 網頁版
  - 重用／快取 API 結果，不做重複請求
  - CC BY-SA 3.0 出處註記（§23.3 標頭格式已含）
  - ⚠ 說明書曾寫「UA 輪替」，與政策（固定識別）衝突——**採固定識別 UA**，
    不輪替。違反政策會整個 IP 被擋。
- ⚠ LoL wiki **無 Cargo 擴充**：`action=cargoquery` 與 `Special:CargoExport` 都回
  「No such special page」——Squad 資料無法 SQL 查，只能抓頁面 Wikitext parse。

### 頁面結構

- **選手頁**：`Infobox player` 有 `birth_date`／`country`／`roles`／`history`／`ids`
  （別名）。⚠ `name` 欄是**真實姓名**（如 Maple 頁 `name=黃熠棠`）——清洗時忽略，
  不進資料。頁題常是消歧義後綴＋REDIRECT（`Maple` → `Maple_(Taiwanese_player)`）。
- **隊頁**：`Infobox team` 有 `region`／`created`／`disbanded`；History 段記更名前身
  （如 Flash Wolves「founded as yoe IRONMEN」）——predecessors 來源之一。
- **賽事頁**：`Garena Premier League/2014/Spring` 模式（斜線路徑），`Infobox league`
  有 `series`／`team_number`／`sdate`／`edate`。GPL 2012 有 `Opening Event` 頁——
  早期覆蓋比預期好，但 2012–2013 逐年度仍要實測（23.7 點名最薄處）。
- **隊員名單**：隊頁與賽事頁用 `{{TimelineSquadAuto}}`／`{{Squad…}}` 模板——S24 抓
  整頁 Wikitext 即可，parse 是 S25 的事。

### 頁題陷阱（S24b／S24c 枚舉必讀，README 已收錄）

1. **首字母大小寫敏感**：`Ahq e-Sports Club`——小寫 `ahq` 直接 MISS（無 redirect）。
2. 消歧義後綴是正式頁題：`Maple (Taiwanese player)`、`Uzi (Chinese player)` vs
   `Uzi (Vietnamese player)` 不同人——實體對齊關鍵欄位。
3. link 格式空格／底線混用：`FATE (Korean player)` 與 `FATE_(Korean_player)` 都出現。
4. **賽事頁題名跨年格式不一**：2017 Worlds qualifier 寫 `LMS/Summer/2017`，MSI 2018
   寫 `LMS/2018/Spring`——S24c 枚舉四大賽區歷年賽段頁時逐格驗證，別抄一種格式。
5. **名次可靠來源**：TeamCard 的 `placement=` **手寫缺漏不可靠**（2017 Worlds TSM
   標 placement=3 實為 13-16；2012–2013 頁無此欄；2025 頁無此欄）。可靠來源＝
   `TeamPrizePool` Slot 的 place＋Playoffs／Group Stage **子頁**（`#section` 引用）＋
   `ShowBracket`。S24c 名次枚舉以子頁為主、placement 只當輔助。
6. GPL 2012 頁面有 `{{Want_to_Help}}` 缺漏標記——S25 遇到同標記的頁面要記下。

### crawl.mjs 用法

```bash
node crawl.mjs enum-cat "Category:Taiwanese Players" --out 清單.txt   # 分類枚舉（主命名空間）
node crawl.mjs check 清單.txt [--out 結果.tsv]                        # 批次存在性（50/req）
node crawl.mjs crawl 清單.txt [--force]                               # 抓取→raw_data/，冪等＋續傳
node crawl.mjs probe "頁題" / search "關鍵字"                          # 單頁探測／找題名
```

實測：13 頁抓取 1 分內完成；重跑全跳過（冪等 ✅）；Maple 重定向落檔正確（manifest
記 `redirectTo`）。延遲 2–5s 內建，**不要並行跑多進程**（延遲是進程內狀態）。
UA 固定識別（政策禁輪替）。raw 檔頭含 CC BY-SA 註記＋來源 URL。

**已落 raw_data/ 的探勘抽樣**：13 頁（GPL 2012×2、Worlds 2012／2017、MSI 2018、
