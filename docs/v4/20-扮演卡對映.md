## 為什麼做這件事

`src/data/roleplay.js`（347 行）是扮演卡系統——賽前放話、媒體採訪、休息室對話、
教練談話。它的設計理念寫在 `src/data/mental.js` 的檔頭：

> 能力值靠訓練骰養，心理值只能靠「扮演」——玩家不能把訓練點投進大心臟，
> 只能一次一次選擇把人演成那樣。

S12 把心理維度換成六維＋聲量，但當時**只做了機械對映讓測試跑得動**
（nerve→comp、chem→trust、fame→fame、ego/rep→暫時丟棄），標了 `TODO(S20)`。
這一站把它做完。

## 範圍

### 要做

**必讀規格**：V4 §9（隱藏心理六維）、`docs/v4/README.md` 的「已定案的設計決定」。

**必讀既有實作**：`src/data/roleplay.js` 全檔、`src/phases/shared.js` 的
`drawRoleplay` 與 `personaBeats`。

**1. 逐卡重新對映**

對映關係（S12 已定案）：

| 舊維度 | 新去處 |
| --- | --- |
| `nerve` 大心臟 | `comp` 抗壓 |
| `chem` 隊友默契 | `trust` 信任 |
| `fame` 知名度 | `fame` 聲量（獨立層，保留） |
| `ego` 自我 | **不留維度**，改由特質副作用承擔 |
| `rep` 風評 | **不留維度** |

⚠ **`ego` 與 `rep` 那批卡要重新安置，不是刪掉。**
一張「爭議發言」的卡在舊體系裡是 `ego↑ fame↑ rep↓`。新體系裡它可以是：
- `conf`（自信）↑ ＋ `trust`（信任）↓ ＋ 聲量↑
- 或者觸發某個帶副作用的特質（V4 §13 的方向）

判斷每張卡的原意，找它在新體系裡的位置。**不要全部丟給 `conf`。**

六維裡 `drive`（動機）、`disc`（紀律）、`resl`（韌性）在舊體系沒有對應——
這一站要為它們寫進扮演卡的結果，否則這三維只能靠事件卡動。

**2. `personaBeats` 的性格特質門檻重寫**

`src/phases/shared.js` 的 `PERSONA_RULES` 六條全部讀舊維度：

```js
{ key: 'trashtalk', tone: 'bold', streak: 5, need: (s) => s.mental.ego >= 74 && s.mental.fame >= 45 },
{ key: 'bigheart', tone: null, streak: 0, need: (s) => s.mental.nerve >= 90 },
{ key: 'glue', tone: 'plain', streak: 5, need: (s) => s.mental.chem >= 86 },
{ key: 'lonewolf', tone: 'bold', streak: 6, need: (s) => s.mental.chem <= 24 && s.mental.ego >= 72 },
{ key: 'idol', tone: null, streak: 0, need: (s) => s.mental.fame >= 72 && s.mental.rep >= 55 },
{ key: 'pariah', tone: null, streak: 0, need: (s) => s.mental.rep <= -75 },
```

`ego` 與 `rep` 沒了，這六條的條件要重寫。`pariah`（圈內毒瘤，原本吃 `rep <= -75`）
最麻煩——新體系沒有可以是負的維度，要換一個表達方式（低 `trust` ＋ 特質？）。

**3. 保住扮演卡與事件卡的界線**

`drawRoleplay` 的檔頭註解寫得很清楚：

> 跟能力事件卡的關鍵差別：**這裡不擲骰決定成敗**。扮演不是賭博——你選了什麼就是
> 什麼樣的人，心理值照著選項直接走。真正隨機的只有外界反應的敘述，而且反應的力道
> 由知名度放大。

**這條界線不要動。** `tests/kernel/roleplay.mjs` 專門守它。

**4. 聲量放大器的機制保留**

「越紅的人，同一句話被放得越大」——`fame` 移到 `reputation.js` 之後這個機制要還在。

### 不要做

- **不要把扮演卡改成擲骰。** 那會毀掉它與事件卡的區隔
- **不要新增扮演卡。** 這一站是對映，不是擴充內容
- **不要碰事件卡**（S18）
- **不要把心理值顯示給玩家。** V4 §9.1 明說不可見
- **不要為了省事把 `ego`/`rep` 那批卡刪掉**

⚠ **lonewolf 終局 0 是合成吃掉，不是門檻錯**：`grinder+lonewolf→machine`、

新體系 trust 沒有負值，低信任用 `≤ 15` 表達「所有人都受不了他」。

### 對映過程中修掉的兩個死路門檻

1. **glue 原 `trust ≥ 86` 是不可達門檻**：對映後 trust 受爭議卡與年底回歸壓制，
   160 段實測上限只有 6x（改前 max 64），86 一人都到不了。改為 `trust ≥ 55`
   （單維度門檻，與 bigheart 的 `comp ≥ 90` 同構）。順手補強 8 張隊內卡的 trust
   正面（+2），否則 55 也只有 6 段。
2. **idol 原 `fame ≥ 72 && trust ≥ 60` 幾乎不可達**：紅路線（fame 高）幾乎必吃
   trust 負面，fame ≥ 72 的段 trust 中位數遠低於 60（交集實測 1／160）。改為
   `fame ≥ 72 && !traits.pariah`——「沒有黑歷史」由毒瘤特質的缺席表達（§9.4 拿掉
   rep 的哲學：切割類判定改讀特質）。嘴砲王不算黑歷史：能紅的嘴砲照樣有粉絲。
