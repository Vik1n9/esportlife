## 為什麼做這件事

V4 §13.1：**每個特質＝益處＋副作用，無純正面、亦無純負面，取得就是取捨。**

v4.3 之後，「具體特質」不再是寫死進 `traits.js`／`epics.js` 的條目，而是**由特質編輯器
（S18a）重新定義的資料**。但編輯器要驗證的 schema、要遵循的規則，必須先由這一站定案：
副作用怎麼分級、互斥怎麼宣告、維持條件怎麼寫、效果能掛在哪一層、素材分哪一池。

這一站同時是「作廢物清理」的掃尾站——v4.3 讓一堆舊效果鍵（`retireAge`／`ratingAdd`／
`giftedDice`／`growthMult`／`injuryAdder`……）失去意義，S15b／S16 移除了它們的消費端，
剩下的死鍵與硬編碼特例在這裡一併清掉。

## 範圍

### 必讀規格

V4 §13（特質系統全節）、§14.1（五種類、天生特質池）、§14.2（四池、兩條配方衛生
規則）、§14.4（掛載點全景表，無限制）、§14.5（特質設計指南）、§9（心理六維）、
§11.2（院長特質範本）。

### 要做

**1. 建立 v4.3 特質 schema（編輯器要驗證的那套）**

定案並文件化特質的資料形狀：益處＋副作用、副作用級別（§13.2 三級）、互斥組（§13.3
第二層）、維持條件（§14.2）、掛載點（§14.4 A~K 十一層）、池歸屬（§14.2 四池，未指定
預設 persona）、種類（common/rare/epic/legend/unique）。效果用 `kernel/modifiers.js` 的
四種寫法（加法／`mul`／`floor`／`cap`／旗標）＋ S15b 的「窗口」表達。

**2. 重定義既有 50 特質到新 schema**

`src/data/traits.js`（26 通用＋8 稀有）與 `src/data/epics.js`（10 史詩＋6 傳說）全部重寫：
每個特質補益處＋副作用（§13.2 三級，益處越強副作用越高）、互斥、維持條件、池歸屬、
掛載點。**傳說維持 6 個**——擴到 20 是 S19b。掛載點可以自由選（§14.4），但效果要有
看得見的消費端（§14.5 第 5 條）。

**3. 作廢物清理（消費端已在 S15b／S16 移除，這裡清資料與殘留參照）**

| 清理 | 位置 |
| --- | --- |
| `retireAge`／`declineOffset`／`declineMult` 死鍵 → 改窗口（`peak_age_shift`／`fall_k_mul`／`decline_pull_mul`） | `traits.js:69`、`epics.js:15/24/75` |
| `ratingAdd`（神之領域 +2）、`abilityCapUp`（突破上限）→ 掛載點自由（§14.4 允許直接加評價，但用 §14.5 的「選對消費端」判斷） | `epics.js:23/76/85/103` |
| `giftedDice`（骰子）→ 改 `growth_rate_mul` 或訓練卡權重 | `traits.js:25`、`epics.js:24` |
| `growthMult`（成長 ×N）→ `growth_rate_mul` 窗口 | `traits.js:118/144`、`epics.js:23/76/85/103` |
| `injuryAdder`（肝帝自爆）→ 訓練卡大失敗效果（§5.4） | `traits.js:118` |
| 硬編碼特例 `epic.ageless`／`traits.veteran` 殘留參照 | `ui/summary.js:61`（其餘 S15b 已清） |

**4. 心理層特質的觸發卡缺口（§21.1）**

§9.1：心理**只能**透過事件卡改變。凡是被定義成合成素材的心理層特質，沒有事件觸發卡
就是死配方——把「哪些特質需要 S18 補卡」清單寫進交接筆記，S18 照著補。

**5. disc／drive／resl 三維內容缺口（S12 交接筆記點名）**

S12 量到 `comp` 65／`conf` 66／`trust` 38、其餘三維（disc／drive／resl）貼在 50。這三維
目前沒有任何卡碰得到——特質重定義時優先讓部分特質掛載這三維（副作用或益處），
把死維度接上內容。

### 不要做

- **不要擴充傳說**（6→20 是 S19b）
- **不要改配方表**（S19c）
- **不要改 `kernel/modifiers.js` 的四種寫法**（窗口讀取 S15b 已加，用既有機制表達）
- **不要讓副作用強到把特質變成負資產**（§13.1 是取捨，不是懲罰）
- **不要碰扮演卡**（S20）
- **不要照抄舊特質的效果鍵**——v4.3 作廢的就是它們

## 規則與不變式

- S07 不變式全綠。**副作用會壓低整體強度**，跑完看巔峰有沒有掉太多
- **每個特質都有副作用**：掃過四階特質表，缺副作用欄位就紅
- **互斥對稱**：A 與 B 互斥，B 也要與 A 互斥
- **抵銷關係至少 3 組**，測試驗證抵銷真的生效
- **維持條件失效要有敘事 beat**
- **作廢鍵清乾淨**：`grep -n "retireAge\|declineOffset\|declineMult\|giftedDice\|growthMult\|injuryAdder" src/`
  輸出為空（`ratingAdd`／`abilityCapUp` 若依 §14.4 重新掛載成合法形式則保留並改名，交接筆記記下）
