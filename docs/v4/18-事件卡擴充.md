# S18 · 事件卡擴充 26 → 80~150

狀態：未開始（進度：26 / 目標 80~150）
前置：S18a
預估：**每批 20 張一個 session**，共 3~6 個 session
推理難度：低
建議模型：Sonnet 5（`claude-sonnet-5`）
理由：判斷成本低——結構由 S17 定好了，照 schema 填。但**文案品質要求高**（每張卡是
玩家會讀的敘事，寫壞了整個遊戲的質感就壞了），所以不降到 Haiku。

⚠ 這一站**刻意分批**。一次寫 20 張，做完更新狀態表的張數，下一個 session 接著寫。
不要試圖一次寫完 100 張。

---

## 為什麼做這件事

現在 26 張卡 / 78 個選項。V4 §19 的 DEMO 是職業第一年、約 12 個月回合，
每回合固定 1 張（有機率 2 張）——**一年就要吃掉 12~20 張**。

26 張撐不起重玩。V4 §1.2 說「事件卡改變隱藏心理、觸發特質，特質合成形成隱藏路線」，
§1.4 說「重玩性來自不同種子＋不同選擇路徑＋隱藏探索」——這些都靠事件卡的數量與
多樣性支撐。目標 80~150 張。

## 範圍

### 要做

**必讀規格**：V4 §12（事件卡系統）、§9（隱藏心理六維——事件是唯一能改變它們的途徑）、
§13（特質雙面性）。

**必讀既有內容**：`src/data/events.js` 的檔頭註解（寫清楚了每個欄位的意思與設計理由）
與現有 26 張卡——**新卡要跟它們同一個聲音**。

**用 S18a 的編輯器寫**：`npm run serve` 之後開 <http://localhost:8080/tools/>。
id 重複、選項數不對、互斥群組沒成對這些會當場紅，不必等 `npm test`。
用法見 `tools/README.md`。手寫也可以，但錯了要自己抓。

**1. 每批 20 張，主題要分散**

不要一批全寫同類型。每批建議的組成：

| 類型 | 張數 | 說明 |
| --- | --- | --- |
| 訓練／日常 | 4~5 | 排位、訓練賽、覆盤、作息 |
| 隊內關係 | 3~4 | 隊友摩擦、教練談話、休息室、換人風聲 |
| 媒體／輿論 | 3~4 | 採訪、社群、直播、粉絲 |
| 賽場情境 | 3~4 | 賽前、賽後、關鍵局、被針對 |
| 生涯／人生 | 3~4 | 家庭、感情、學業、健康、退役念頭 |
| 版本／英雄池 | 2~3 | 大改版、新英雄、拿手英雄被砍 |

**2. 每張卡的必備欄位**（結構由 S17 定，這裡是內容要求）

- **敘事文本**：具體的場景，不是抽象描述。看現有的 `solo_queue` 那張——
  「凌晨兩點，訓練室只剩你這台還亮著」比「你在打排位」有力得多
- **2~4 個選項**：每個選項是**真的取捨**，不是「好選項 vs 壞選項」。
  安全牌的代價是它不會把你推向任何極端（現有卡的 `traits: false` 就是這個意思）
- **觸發條件**：時代／屬性範圍／特質／心理範圍／賽季階段。沒條件的就是隨機池成員
- **優先度**與**互斥群組**
- **結果**：屬性／體力／心理六維／特質線索

**3. 心理六維要被寫到**

V4 §9.1：心理**只能**透過事件卡改變。所以這一站的卡片是六維唯一的來源。
每批 20 張要確保六個維度都有卡在動它們，不能全部集中在抗壓與動機。

**4. 特質線索要鋪**

V4 §13.4：特質來源有「出生自帶、生涯條件、事件獲得」。事件獲得的特質，該事件之後
不再觸發。新卡要為 S19 的特質目錄鋪路——但**不要自己發明特質**，用 S19 定的清單
（若 S19 還沒做，先寫不掛特質的卡，或在交接筆記記下需要哪些特質）。

**5. 收工時更新進度**

改 `docs/v4/README.md` 狀態表 S18 那列的張數。狀態維持「進行中」直到達標。

### 不要做

- **不要一次寫超過 20 張。** 額度會爆，而且後半的文案品質必然下滑
- **不要改觸發引擎**（S17 已定案）
- **不要發明新的結果欄位。** schema 由 S17 定，需要新欄位就回報
- **不要寫「純好」或「純壞」的選項。** V4 §13.1 的雙面性精神也適用於事件選項
- **不要碰扮演卡**（`data/roleplay.js`，S20）
- **不要調平衡數值。** 單張卡的效果幅度參照現有卡的量級

## 規則與不變式

- S07 不變式全綠。**每批寫完都要跑**——20 張新卡足以讓平衡跑掉
- **卡片 id 唯一**：新卡的 id 不與既有的撞
- **互斥群組要成對**：標了互斥的卡要真的有另一張同群組的卡，否則互斥沒有意義
- **每張卡的選項數在 2~4**（§12.2）
- **不要讓某一維心理被過度餵養**。每批寫完統計六維各被幾張卡動到，抄進交接筆記
