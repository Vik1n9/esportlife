# 四階特質合成：把隱藏特質改成 LoL 道具合成

**日期**：2026-08-12
**狀態**：設計定案，已實作

## 問題

隱藏特質原先是「基礎 → 史詩」兩層。玩家培養的樂趣與節奏應該來自**大量的事件**與
**更多特質**，以及特質之間的**合成**——每個玩家藉由事件卡的選項解鎖不同特質，再像
LoL 道具合成那樣把素材往上疊。舊制只有一層合成，可探索的配方與取捨太少。

## 目標

- 合成分**四階**：通用 → 稀有 → 史詩 → 傳說，概念取自 LoL 道具合成（小件疊終極裝）。
- 大量新增事件卡與特質，取材自 LoL 社群、真實賽事與實況圈梗。
- **不破壞既有平衡**：實測 160 段生涯的等第分布與平均巔峰 OVR 必須維持在舊版水準。

## 四階架構

| 階層 | 比喻 | 取得方式 |
|---|---|---|
| 通用 | 小件 | 事件卡選項、性格扮演、生涯成就（困難取得） |
| 稀有 | 合成件 | 2 個「人格／媒體」類通用合成 |
| 史詩 | 核心大件 | 2～3 個「競技表現」類通用合成（沿用既有核心配方） |
| 傳說 | 神話終極裝 | 1 個史詩＋1 個稀有合成 |

## 關鍵設計取捨：素材分兩池

第一版把「稀有 → 史詩」做成嚴格階梯（2 稀有 → 1 史詩、史詩再往上疊），結果 160 段
生涯的史詩持有率從基準 71/80 掉到 10/80、平均巔峰 OVR 從 60.5 掉到 57.5——因為稀有
配方跟史詩配方搶同一批稀缺的通用素材，稀有先檢核就把史詩的素材吃光了。

修正：**稀有吃「人格／媒體」類通用（人氣、膠水、獨狼、神主牌、肝帝、梗王、鏡頭感、
守護者），史詩吃「競技表現」類通用（天才、鐵人、自律、單身、老將……），兩池不重疊**。
如此稀有與史詩能同時成立、互不搶素材；傳說＝史詩＋稀有，素材必然分屬兩池。

實測結果（160 段生涯，與基準 60.5 / 71 史詩比對）：

| 指標 | 基準 | 新版 |
|---|---|---|
| 平均巔峰 OVR | 60.5 | 59.9 |
| 史詩持有率 | 71/80 | 63/80 |
| 稀有持有率 | — | 69/80 |
| 傳說持有率 | — | 23/80 |

## 平衡不變式

- 老手打法的傳奇不得超過三成；新手打法的傳奇要罕見（不到老手三分之一）。
- 老手平均巔峰 OVR 至少比新手高 1.5。
- 五個生涯等第都出現得到。

頂端加成刻意用**成長×N 與突破上限**（練得越準越吃得到），而不是平白加分——平白加分
會幫新手打法也越過傳奇門檻，破壞「傳奇要罕見」的不變式。實測時把傳說加 `careerScore`
會讓新手打法出現傳奇、`spread*3 <= focus` 失敗，故棄用。

## 資料結構

`FUSIONS` 配方從單一的 `needTier + need[]` 改成**每個素材自帶階層**的 `[tier, key]`
配對，`engine/progression.js` 的 `checkFusions` 據此跨階消耗；`state` 新增 `rare`／
`legendary` 兩槽，`kernel/modifiers.js` 用 `TIER_STORES` 統一查詢四階效果。

## 事件邏輯修正：選項自帶結果

事件卡原本只有卡片層級的 `good/bad`，但像「暫時關台」這種跟卡片主軸相反的路，套用
「開台時間控制得宜」的通用結果會牛頭不對馬嘴。選項新增 `on` 欄位攜帶自己的 `good/bad`，
`drawEvent` 命中時優先使用。受影響的選項：`streaming.close`、`solo_queue.stop`、
`scrim.rest`、`endorsement.reject`、`vod_review.skip`、`roster_drama.avoid`。
