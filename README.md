# 電競人生：LoL 職業選手生涯模擬 ⚡

這是一款純文字的 **LoL 電競選手生涯養成遊戲**。從 S2（2012）入行開始，經歷網咖盃賽、試訓、主場賽區（GPL→LMS→PCS→LCP）、海外頂級賽區（LCK／LPL／LEC／LCS），一路打到 MSI 與世界賽。版本、英雄池、轉會、解散與隱藏特質合成，每顆骰子與每個選擇都算數。

👉 **[點我直接遊玩](https://vik1n9.github.io/esportlife/)**

> 專案已由 YaKyuLife（棒球版）更名為 **esportlife**。
> 舊網址 <https://leoggcat.github.io/yakyulife/> 是另一個帳號的舊部署，停留在 v2，不再更新。

## 遊戲特色

* **中度史實演進**：主場聯賽隨年份演進（GPL→LMS→PCS→LCP）、MSI（2015+）、世界賽 Swiss（2023+）、薪資隨時代調整。
* **老將長壽機制**：對照 Faker 型頂級選手可打到 30+；衰退曲線由年齡與特質決定，基礎退役硬上限 34，可延後至 40。
* **歷史解散與改寫**：真實在該年解散的隊伍，若玩家在隊且未帶隊奪世界冠，季末強制解散進入自由市場；自由市場不達標者強迫退休。
* **特質合成（完全隱藏）**：多個基礎特質同時持有時自動合併成史詩特質（如「不老傳奇」＝老將＋自律＋單身），配方從不揭露。
* **五路養成**：上路／打野／中路／射手／輔助，搭配 8 隻真實英雄池、版本 Meta 與位置加權 OVR。
* **英雄池會成長**：出賽累積專精，池越深越吃得住版本大改動。
* **人生隨機事件**：手腕傷病、宵夜誘惑、單身誘惑、媒體專訪、代言、隊內矛盾、海外集訓等，場外決定影響生涯。
* **細緻數據**：K/D/A、CS、視野、傷害占比、單殺、MVP，逐季累積結算。
* **隨時查閱選手資料**：能力與潛力刻度、英雄專精、版本落差、隊友與教練、合約狀態、已覺醒素質。
* **存檔續玩**：每年年初自動存檔，關掉分頁也接得回來。

## 遊玩方式

- 開局選擇 **ID 與位置**，可輸入自訂種子碼（同種子＋同選擇＝同一段人生）。
- 每季三階段：**季初訓練**（擲骰加點）→ **賽季**（事件＋傷病＋數據＋季後賽）→ **休賽期**（國際賽＋薪資＋轉會／FA／解散）。
- 22 歲前累積 5 次擲出「6」可覺醒隱藏素質。
- 右上角 **☰** 隨時打開選手資料面板；**↺** 重新開始。

## 本機開發

零建置、零相依。但 ES modules 需要 HTTP 協定（直接開 `file://` 會被 CORS 擋），所以請起一個靜態伺服器：

```bash
python3 -m http.server 8080
```

然後開 <http://localhost:8080>。

跑回歸測試（需要 Node 18+，不需要 `npm install`）：

```bash
node tests/headless.mjs
```

引擎完全不依賴 DOM，所以這支腳本會在 Node 裡實際跑完 160 段生涯，並驗證種子決定論、
生涯評價分布、特質合成、版本落差方向與解散名單過濾。
