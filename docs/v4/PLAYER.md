# 電競人生：LoL 職業選手生涯模擬 — 遊戲說明書

---

## 一、這是什麼遊戲

這是一款以英雄聯盟職業電競為題材的單局制養成遊戲。玩家扮演一名 LoL 職業選手，從出道到退役，經歷一段完整的電競生涯。每一局遊戲就是一個人的職業人生。

遊戲類型結合了 Rogue-like（隨機事件、隱藏探索、每局不同）與賽馬娘式養成（月份制回合、訓練設施、體力管理）。

單局目標時長為 30 至 50 分鐘，約包含 100 至 130 個決策點。大部分的人生是平庸或邊緣選手，傳奇生涯是稀有的——這是刻意的設計。

---

## 二、核心體驗

每一局遊戲提供四層體驗：

**養成管理**：每月選擇一項行動（訓練、休息、復健等），管理體力，追求目標技能成長。

**敘事儀式感**：賽事不是單純的數字結算，而是以「賽前敘事、備賽選擇、比賽過程、結果呈現、賽後採訪」五拍結構呈現，讓每一場比賽都有重量。

**Build 探索**：事件卡會改變選手的隱藏心理狀態、觸發特質，特質之間可以合成出更高階的特質，形成隱藏的成長路線。玩家不被告知配方，需要透過觀察與推導來發現。

**替代性生涯路線**：不是只有世界冠軍才是成功的結局。賽區統治者、不滅隊魂、流浪傭兵等路線，同樣是有名字、有價值的生涯終點。

---

## 三、設計原則

本遊戲遵循四條設計原則：

**直覺性**：所有遊戲中的變化都能用現實電競邏輯推導出來。玩家不需要查攻略，憑電競常識就能理解因果關係。對 LoL 粉絲而言，這意味著遊戲中的每一個機制都能在真實電競中找到對應。

**不農**：拒絕無決策意義的重複操作。遊戲中沒有任何機制要求玩家做重複且無趣的事。每一次選擇都應該有意義。

**無死路**：遊戲中所有可追求的目標，都必須存在至少一條邏輯上可達的路徑。不存在「永遠拿不到」的內容。

**多層次目標**：即使無法達成最高目標（如世界賽冠軍），遊戲仍然提供足夠的挑戰與樂趣。平庸的人生也有值得追求的終點。

---

## 四、選手的三層能力

每位選手的能力由三個層次構成：

| 層次     | 玩家是否可見 | 來源      | 用途           |
| ------ | ------ | ------- | ------------ |
| 六屬性    | 可見、可訓練 | 訓練活動成長  | 選手的基礎身體與心智能力 |
| 十二技能   | 可見     | 由屬性自動計算 | 教練與觀眾評價選手的依據 |
| 隱藏心理六維 | 不可見    | 僅由事件改變  | 影響比賽中的發揮穩定度  |

核心概念：屬性決定技能的「數值高低」，心理決定技能的「發揮穩定度」。同一個 72 分的團戰技能，抗壓高的人在大賽中發揮得出來，抗壓低的人會失常。這個差距是隱藏的，玩家需要從比賽文本中觀察與推測。

---

## 五、六屬性

| 屬性  | 在峽谷中的含義            |
| --- | ------------------ |
| 體能  | 手腕續航、整季訓練量、團戰穩定    |
| 靈巧  | 反應手速、閃現躲技、極限補刀     |
| 意識  | 地圖意識、兵線理解、對方打野位置判斷 |
| 技巧  | 技能命中、連招精度、英雄熟練上限   |
| 默契  | 團隊協作、溝通、開團跟隨       |
| 決斷  | 何時開團、何時撤退、敢不敢做決定   |

屬性範圍為 0 至 100。每位選手出生時，六個屬性的潛力天花板各不相同：一項頂尖、一項優質、一項中上、三項平庸。潛力是軟天花板——練得夠久仍然可以超越，只是成長速度會明顯變慢。

屬性會隨年齡變化：靈巧、體能、技巧三項在 30 歲後開始衰退；意識與決斷是經驗型屬性，衰退期仍有機會繼續成長；默契不受年齡影響。

---

## 六、十二技能

技能是選手的「場上身份」，由屬性加權計算而來，範圍 0 至 100。十二項技能分別對應真實比賽中的決策面向：

對線、操作、視野、節奏、支援、資源控制、會戰、開團、保護、邊線處理、轉線運營、走位。

每個位置（TOP、JG、MID、ADC、SUP）有自己的核心技能與次要技能。例如：ADC 的核心是走位與操作，輔助的核心是開團與保護，打野的核心是節奏與資源控制。

玩家可以看到自己的十二項技能數值，並據此判斷應該訓練哪些屬性。

---

## 七、隱藏心理六維

這是遊戲中最深的隱藏層。六個心理維度完全不可見，玩家只能從比賽文本、事件結果與選手的表現中推測：

| 維度  | 影響範圍                    |
| --- | ----------------------- |
| 抗壓  | 大賽與關鍵局的發揮、被對手施壓時的失誤     |
| 自信  | 高風險操作的意願、訓練效率、過度自信會導致貪戰 |
| 動機  | 訓練收益、倦怠事件、退役意圖          |
| 紀律  | 享樂抗性、體力管理、非受迫性失誤        |
| 信任  | 隊內協作、默契判定、轉會適應          |
| 韌性  | 連敗後的恢復、傷病回歸、受迫性失誤       |

心理素質無法透過例行訓練改變，只能透過事件卡的選擇來影響。

**失誤系統**：比賽中的失誤分為兩種。受迫性失誤（被對手施壓而失誤）主要受抗壓與韌性影響；非受迫性失誤（自身疏忽、貪戰、沒看地圖）主要受紀律與自信影響。失誤的「原因」（心理）是隱藏的，但「結果」（陣亡、關鍵技能失手）是可見的——玩家需要從結果推測原因，形成探索循環。

## 八、時間結構與回合制

### 生涯階段

業餘期（網咖盃賽）→ 職業期（主場賽區或海外聯賽）→ MSI → 世界賽

### 月份制回合

職業期以「月」為回合單位。每月玩家選擇一個行動，節奏明快。一年約有 12 個養成回合加上賽事事件序列。

### 單年結構

| 月份        | 階段            |
| --------- | ------------- |
| 1 月       | 休賽期（轉會、續約、集訓） |
| 2 至 3 月   | 春季常規賽         |
| 3 至 4 月   | 春季季後賽         |
| 5 月       | MSI（若出線）      |
| 5 至 8 月   | 夏季常規賽         |
| 8 至 9 月   | 夏季季後賽         |
| 10 至 11 月 | 世界賽（若出線）      |
| 12 月      | 休賽期           |

10 年職業生涯約有 80 至 90 個養成回合與 20 至 40 個賽事事件序列。

## 九、訓練系統

### 核心規則

訓練不是選擇「練哪一項屬性」，而是選擇「做什麼訓練活動」。每個活動同時影響多項屬性，但權重不同。

### 訓練活動

| 訓練活動   | 主要幫助        |
| ------ | ----------- |
| 個人機械訓練 | 操作、走位       |
| 強化訓練賽  | 會戰、開團       |
| 戰術復盤   | 轉線運營、資源控制   |
| 體能健身   | 續航、抗傷       |
| 排位衝分   | 混合能力，附帶風險   |
| 英雄池練習  | 擴充英雄池、練習新英雄 |
| 休息     | 恢復體力        |
| 復健預防   | 降低受傷風險      |

每月行動就是從上述清單中選擇一項。不同活動對不同位置的效益不同，形成位置化的訓練取向。

### 成長與成功率

每次訓練有成功、大成功、失敗三種結果。大成功獲得額外成長，失敗則消耗體力但不獲得成長。成功率受體力、相關心理素質與特質影響——體力過低時，訓練失敗的風險會顯著上升。

---

## 十、體力系統

體力是養成回合中的核心資源，範圍 0 至 100。

- 訓練消耗體力，休息恢復體力。
- 比賽也會消耗體力，走得越深的賽事消耗越大。
- 體力過低時，訓練成功率下降，受傷風險上升。
- 賽事期間無法選擇休息，只能透過備賽戰術中的「心態調整」恢復少量體力。

設計意圖：玩家需要在「多練」與「休息」之間做出取捨。一直訓練不休息會導致狀態崩盤，但過度休息則會錯失成長機會。保守玩法大約每 3 至 4 個月休息一次。

---

## 十一、事件卡系統

### 觸發規則

每個月固定觸發 1 張事件卡，有機率觸發 2 張。事件卡分為兩種來源：

- **條件事件**：當選手的狀態滿足特定條件時觸發（例如：連敗後觸發心態事件、轉會期觸發報價事件）。條件事件有優先級，優先於隨機事件。
- **隨機事件**：從隨機池中抽取，代表生涯中的意外與機遇。

### 事件卡的內容

每張事件卡包含一段敘事文本與 2 至 4 個選項。每個選項會產生不同的結果：改變屬性、消耗或恢復體力、影響隱藏心理、觸發特質線索、或引發後續事件。

### 生涯任務卡

與一般事件卡不同，生涯任務卡由生涯狀態的長期積累觸發，開出一個跨回合的目標與期限。玩家需要在期限內完成目標。

生涯任務卡分為兩種：

- **傳說任務卡**：觸發條件嚴格（通常要求國際賽四強以上的經歷加上特定特質組合），達成後獲得傳說特質。這是遊戲中最稀有的成就。
- **路線任務卡**：觸發條件基於生涯軌跡（例如：在同一支隊伍待超過 6 年、效力過 4 支以上不同戰隊），達成後獲得史詩特質與生涯標籤。這是平庸局的主要終點。

一個 run 中可以同時持有多張進行中的任務卡，也可以達成多個傳說。傳說的稀缺性由觸發條件與達成目標的難度控制，而非機制上的數量限制。

## 十二、特質系統

### 雙面性

每個特質都是一體兩面：它帶來益處，同時也帶有副作用。越強的特質副作用越大。遊戲中不存在純正面的特質，取得特質本身就是一種取捨。

### 特質階級

| 階級  | 說明                     |
| --- | ---------------------- |
| 通用  | 基礎特質，最常見，是合成的素材        |
| 稀有  | 由 2 個通用特質合成            |
| 史詩  | 由 2 至 3 個通用特質合成        |
| 傳說  | 由生涯任務卡達成後獲得，不由配方自動合成   |
| 獨有  | 不可合成、不能當素材，由特定生涯條件直接授予 |

### 天生特質

種子生成時，玩家有 40% 的機率沒有天生特質、40% 的機率有 1 個、20% 的機率有 2 個。不存在 3 個以上天生特質的角色。天生特質只包含基礎人格與體質類型（例如：天生抗壓、玻璃體質、天生領袖），不包含競技表現類型。天生特質歸入通用特質池，可以作為合成素材。

### 合成機制

取得特質後，系統自動檢查是否滿足合成條件。合成後，低階素材被消耗，不可再取。玩家不被告知配方，僅透過氛圍敘事暗示，需要靠觀察與社群探索來發現。

合成路徑不是嚴格階梯：通用特質可以直接合成稀有，也可以直接合成史詩，兩者互不干擾。傳說的獲得則完全依賴生涯任務卡的達成，而非素材的自動合成。

### 替代性生涯路線

對於無法達成世界冠軍的平庸局，遊戲提供五條替代路線：

| 路線    | 核心意象        |
| ----- | ----------- |
| 賽區統治者 | 國內無敵，國際賽掙扎  |
| 流浪傭兵  | 換隊如換衣，處處留痕  |
| 不滅隊魂  | 一人一城，王朝基石   |
| 究極綠葉  | 犧牲個人數據，成就團隊 |
| 網紅選手  | 成績平庸，聲量頂尖   |

這些路線彼此之間高度互斥（不滅隊魂與流浪傭兵不可能同時成立），且每條路線都有明確的觸發條件與達成目標。達成後獲得史詩特質與生涯標籤，作為該局生涯的終點。

## 十三、賽事呈現

### 常規賽

常規賽以文字播報形式呈現，逐場列出結果，玩家不直接互動。每月結算時，比賽結果會影響屬性、特質線索與心理素質。

### 季後賽、MSI、世界賽

這些賽事以事件序列呈現，每場 BO（系列賽）包含五個階段：

1. **賽前敘事**：對手介紹、賽區背景、輿論氛圍。
2. **備賽戰術選擇**：玩家從 3 至 4 個戰術選項中選擇一個（例如：針對對手弱點研究、強化自身體系、心態調整與休息、高強度集訓）。
3. **戰術結算**：固定效果加上隨機事件判定。
4. **比賽模擬**：自動模擬比賽過程，呈現逐局比分與關鍵數據摘要。
5. **賽後敘事**：採訪、輿論反應、心理結算。

### 備賽戰術的取捨

賽事期間不能選擇「休息」行動。戰術選擇的核心取捨是：高強度集訓能提升表現但大幅消耗體力且增加受傷風險；心態調整能恢復少量體力但戰術收益較低。走得越深的賽事，帶進下一輪的身體狀況越差。

### 生死戰（區域資格賽）

單場定生死的高壓事件序列。抗壓低的選手在此處受迫性失誤會被放大。戲劇性優先。

## 十四、比賽與勝負

### 玩家影響力

玩家對團隊勝率的影響力權重為 60%，隊友佔 40%。這意味著個人能力很重要，但一個人打不贏整支隊伍——即使是最強的選手，也無法在極端劣勢下保證勝利。

### 對手強度

對手的強度隨賽事等級提升：

- 常規賽對手較弱，這是刻意的——讓玩家有空間探索不同的成長路線。
- 季後賽逐輪提升，從八強到決賽難度遞增。
- MSI 與世界賽有絕對強度下限——不會因為玩家來自弱賽區，國際賽的對手就變弱。這是「國際賽會吃掉你」的核心來源。

### 個人表現與勝負分離

個人數據表現與團隊勝負是分離的。強選手在弱隊中仍然可以刷出亮眼的個人數據，但比賽可能一直輸——這支撐了「院長」類型的特質（數據漂亮但比賽輸）。

## 十五、國際賽資格

### MSI

MSI 是俱樂部賽事，門票發給戰隊。2015 年創辦，2020 年因疫情停辦。2015 至 2022 年僅賽段冠軍出線，2023 年起冠軍與亞軍均可出線。

### 世界賽

世界賽資格有三個通道：

1. 夏季季後賽冠軍直接出線。
2. 全年冠軍積分累積達標者出線。
3. 區域資格賽（生死戰）爭奪最後席位。

玩家透過對團隊勝率的貢獻影響出線與否。強選手在弱隊中可能整年打不進世界賽，這驅動了轉會的動機。

## 十六、時代演進

遊戲涵蓋 LoL 電競的完整歷史進程：

| 時代  | 年份           | 主場聯賽 | 薪資規模 |
| --- | ------------ | ---- | ---- |
| 草創  | 2012 至 2014  | GPL  | 最低   |
| 成熟  | 2015 至 2019  | LMS  | 中低   |
| 全球化 | 2020 至 2024  | PCS  | 中等   |
| 現代  | 2025 至 2036+ | LCP  | 最高   |

時代影響聯賽名稱、MSI 的存在與否、世界賽格式（小組賽或 Swiss 制）與薪資規模。選手的出生年份決定了他從哪個時代開始職業生涯。

## 十七、生涯與退役

### 衰退

30 歲後，靈巧、體能、技巧三項屬性開始逐年衰退。意識與決斷不受影響，仍有機會繼續成長。特定特質可以延緩衰退或提前衰退。

### 退役

基礎退役年齡上限為 34 歲，特定特質可以延長（最高至 41 歲）。當選手在自由市場上無法獲得任何報價時，將被迫退役。

### 解散事件

戰隊可能因戰績不佳而解散。若該季玩家所屬隊伍贏下世界賽冠軍，解散可以被避免。未避免則季末強制進入自由市場。

## 十八、生涯傳記

單局結束時，系統根據玩家收集的特質、達成的生涯路線與關鍵事件，自動生成一段「電競新聞報導」或「維基百科式」的生涯總結文本。

這段傳記基於已發生的事實拼接而成，不依賴隱藏條件。同一段生涯必定產出同一篇傳記。

設計目的：在無局外成長的網頁遊戲框架下，讓每一局——包括平庸局——都留下獨特的歷史定位與敘事收束。不是只有冠軍的人生才值得被記錄。

---

## 十九、重玩性來源

每一局遊戲的差異來自三個維度：

**不同的種子**：出生天賦（屬性潛力分佈、位置適性、天生特質）不同，起始條件不同。

**不同的選擇路徑**：每月的訓練選擇、事件卡的選項、備賽戰術的取捨，構成了完全不同的生涯軌跡。

**隱藏探索**：特質合成配方不公開，生涯任務卡的觸發條件需要玩家從電競邏輯中推導。每一局都可能發現新的路線與組合。

## 二十、DEMO 範圍

DEMO 版本跳過業餘期，直接從職業第一年開始。玩家已在主場賽區的職業隊中，打完整的**三個賽季（36 個月）**——合約到期與續約、轉會窗口、生涯任務的期限、生命週期的衰退斜率都要跨年才看得到，一年的範圍測不到它們。

三年之內若走到任何一種結局（市場淘汰、解散無人接手、退役事件），生涯就在那裡結束；若三年跑完仍未觸發任何結局，畫面會顯示「DEMO 結束」——**這不是退役**，而是 DEMO 的紀錄到此為止，接著比照退役結算一次生涯（生涯檔案、數據、榮譽、生涯傳記）。狀態列的年份格會顯示期程進度（例如「DEMO 14/36」）。

驗證核心玩法後，正式版再擴展至完整生涯（補業餘期、拿掉期程上限）。
