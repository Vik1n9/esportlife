# S12 · 六維心理 ＋ 聲量層 ＋ 失誤系統

狀態：✅ 完成
前置：S11
預估：1 session
推理難度：**高**
建議模型：Opus 5（`claude-opus-5`）
理由：心理是「放大器不是決定器」——這句話的實作邊界很窄，係數大一點就變成心理決定
一切、小一點就變成裝飾。而且失誤系統要讓「因隱藏、果可見」成立，玩家才推測得出來。
降級的風險是做出一個數字上存在、玩法上感覺不到的系統。

## 為什麼做這件事

V4 §9 用競技心理六維取代現行的 nerve/chem/ego/fame/rep。這兩組**不是同一條軸**：

| 現行（社交／聲量） | V4（競技心理） |
| --- | --- |
| `nerve` 大心臟、`chem` 隊友默契、`ego` 自我、`fame` 知名度、`rep` 風評 | `comp` 抗壓、`conf` 自信、`drive` 動機、`disc` 紀律、`trust` 信任、`resl` 韌性 |

V4 §9 只定義了新的六維，沒說薪資談判、轉會、切割改讀什麼——**已定案**
（見 `docs/v4/README.md`）：

- 薪資／試訓／續約／FA 讀 §10.2 教練評價（S11 已完成）
- `fame`（聲量）**保留為獨立層**
- `chem`（隊友默契）併入 `trust`
- `ego`（自我）不留維度，改由特質副作用承擔放大器角色
- `rep`（風評）不留維度，切割判定改讀教練評價＋特質副作用

核心分離（V4 §2）：**屬性決定技能「數值」，心理決定技能「發揮穩定度」。**
同一個 72 的會戰技能，抗壓高的人大賽發揮得出來，抗壓低的人會失常。

V4 §9.2 的發揮公式：

```
技能發揮 = 技能值 × (0.85 + 0.30 × 心理修正值)
心理修正值 = Σ(主導心理維度 × 權重) 正規化到 0–1
```

心理 50 為基準（修正 ≈ 1.0），低於打折、高於加成。**係數 0.85／0.30 是規格書給的，
不要自己改**——那組數字定義了「放大器不是決定器」的邊界（極端心理只造成 ±15% 的
發揮差距）。

若沒有，停下來寫進交接筆記，不要自己發明。

**4. V4 §9.3 失誤系統**

```
失誤率 = 基礎失誤率
       + 受迫項：f(抗壓低) × 壓力係數（大賽/生死戰/被針對時放大）
       + 非受迫項：f(紀律低) + f(自信過高)
失誤結果 → 反映在可見數據（陣亡、關鍵技能失手、會戰先倒）
```

設計要點：**因（心理）隱藏，果（陣亡、失手）可見**。玩家從數據推測心理，這是隱藏
探索循環的來源。所以失誤一定要**進 `season.js` 的可見數據**（陣亡數、關鍵局表現），
不能只是一個內部數字。

注意「自信**過高**」也是失誤來源（過自信→貪）——這是雙向的，不是越高越好。

## 交接筆記

### 一、⚠ 先讀這一節：§9.2 上線之後，`OPPONENT_SUPPORT` 必須從 6.5 調到 9.0

說明書預期這一站的平衡工作是「把心理修正的係數抓在放大器的邊界內」。**那件事確實
發生了（見第二節），但更大的地雷在對手那一邊**：

§9.2 的心理穩定修正是**乘法**進 `positionPower`，而它不只發生在玩家身上——階梯上
那些賽區冠軍等級的隊伍，它們的 carry 也活在 §9.2 底下。S11 推導 `OPPONENT_SUPPORT
= 6.5` 時（3.5 教練/體力 ＋ 3.0 對手明星項）還沒有這個乘法項，所以那個 3.0 是拿
**沒有加成的 carry** 算出來的。照 6.5 實作等於「我方吃 §9.2，對面不吃」。

| 指標（640 段） | S11 | 照 6.5 實作 | 改成 9.0 |
| --- | --- | --- | --- |
| 世界冠軍人均 | 0.113 | **0.248** | 0.128 |
| 有國際冠軍當量的生涯 | 122 | **150** | 123 |
| 打進主流賽區 | 288 | 289 | 277 |
| 平均生涯薪資 | 10993 | 11413 | 11273 |

9.0 是**推導出來再由實測確認**的，不是湊出來的：實測 640 段生涯，有國際冠軍那一群的
`stability` 平均是 1.04，所以同一個階梯 carry（par+17.5 = 83.5）→ ×1.04 = 86.8，
超出 par 從 17.5 變 20.8，§11.1 的明星項公式 `0.06 × 20.8^1.35` = **3.56**（S11 算的是
3.0），再加上它在自家隊伍強度裡多出的份額 `3.3 × 0.60` = **2.0**。3.5 ＋ 3.56 ＋ 2.0
= **9.06**。完整推導寫在 `kernel/strength.js` 的常數註解上。

**排除過的兩個假設**（都跑了 640 段）：

- 「贏了長抗壓、抗壓又幫你贏」的回饋迴圈 → **不是**。把 MSI／世界賽的 `comp` 獎勵
  減半，世界冠軍人均 0.248 → 0.253，完全無效。
- 根因是不是 §9.2 → **是**。把 `stability()` 釘成 1，直接回到 0.125。

⚠ S11 說 `OPPONENT_SUPPORT` 是它對 §17.2 的唯一偏離。這一站沒有新增偏離，只是把
同一個常數重新推導了一次——**後面任何一站只要動到 `positionPower` 的乘法項，都要
回來重算它**。

### 二、§9.2 進來之後，兩條 v3 的心理加成必須讓路（重複計價）

`0.85／0.30` 一個字沒動（規格書與說明書都明令）。但接上去之後，S07 那條
「戰力持平時心理造成的勝率擺幅 ≤ 30 個百分點」**直接紅了，量到 35.3**。

拆解（決勝局＋第一種子＋rookie 探針）：

| 來源 | pp | 處置 |
| --- | --- | --- |
| §9.2 發揮倍率（`positionPower` 乘法） | **17.8** | 規格書寫死，不准動 |
| 信任 → 隊友均值（`trustBonus`，v3） | 8.5 | 係數 0.12 → **0.08** |
| 抗壓 → 決勝局（`clutchBonus`，舊 `nerveBonus`，v3） | 9.0 | 係數 0.16 → **0.05** |

理由是**重複計價**不是調鬆：那兩條吃的正是 §9.2 已經在吃的 `trust` 與 `comp`。各自
砍到剩下「§9.2 表達不了的那一半」——信任那條留下的是「隊友願意怎麼跟你打」（§9.2
管的是你自己），抗壓那條留下的是「決勝局額外的那一份」（§9.2 是恆常的）。改完 28.5 pp。

⚠ **大心臟的份量因此改由特質層承擔**（`bigheart` +5、終極舞台保底 4 再 +4、心態崩盤
翻負），原始 `comp` 只給一點傾斜。S19a 調特質時要知道這些數字現在是主角。

### 三、失誤的可見度（說明書指名要附的數字）

160 段樣本、`state.deathLog` 分 `regular` 與 `pressure` 兩格記每場陣亡數：

| 分組 | 大賽 − 常規賽的每場陣亡數 |
| --- | --- |
| 低抗壓（comp < 40，n=171） | **+0.123／場** |
| 高抗壓（comp ≥ 80，n=341） | **−0.063／場** |
| 全樣本平均 | 常規賽 1.236 ／ 大賽 1.226 |

**全樣本幾乎持平是刻意的**：§9.3 是重分配不是通膨。壓力係數只乘在「短缺」那一半
（`mistakeFactor` 的註解寫了理由）——抗壓低的人在生死戰被放大到兩倍多，抗壓高的人
拿到的減免跟常規賽一樣多，**不會因為場合變大而多領獎金**。對稱放大會變成「抗壓高在
大賽反而更不會死」，等於再發一次獎金給已經吃到 §9.2 與決勝局加成的人。

⚠ **陣亡數目前只進畫面，不進任何結算。** `career.js` 的 `seasonScore` 有擊殺權重、
沒有陣亡權重，所以失誤的代價目前純粹是「數據難看」與玩家自己的推測。這是刻意停在
說明書畫的線上（「失誤一定要進 `season.js` 的可見數據」＝ 觀察循環，不是計分循環），
但**如果 S15 覺得失誤該有競技代價，那一條權重是最小的施力點**，不要再開新機制。

### 四、`ego`→`conf` 是這一站唯一一個沒照 §9.4 字面走的決定

§9.4 寫 `ego` 不留維度、`ego/rep` 機械對映時「暫時丟棄」。**`rep` 照做了，`ego` 沒有
——它對映到 `conf`。**

理由：§9.4 說 ego 不留維度，講的是它**放大聲量的角色**改由特質副作用承擔（嘴砲王／
獨狼／圈內毒瘤），而 ego 的另一半（把自己看得多大）跟 `conf` 根本是同一件事。整個
丟掉的話，**18 張扮演卡沒有任何一張碰得到 `conf`**，於是 §9.3 明文要求的「自信過高
→ 貪」那條雙向設計永遠驗不到，`conf` 會是一個出生就決定、之後再也不動的死維度。

要回退的話：把 `data/roleplay.js` 裡所有 `conf:` 改回丟棄即可，引擎不必動。

✅ **這個決定已經在 PR #9 由專案擁有者確認採用**，並定了一個後續方向：**六維都要有
「超出界限的副作用」**（`conf` 的過自信→貪只是第一個），執行時機在 **V4 完工之後**。
方向與各維度的草案已寫進 V4 §21.3，不在這一站也不在 S19a／S20 的範圍內。

**內容缺口（S19a／S20 的活）**：對映之後 `disc`／`drive`／`resl` 三維沒有任何一張卡
碰得到，只有出生的 ±10 天賦差。這一條已經寫成 `tests/kernel/roleplay.mjs` 的檢查
（三維被接上時會紅，逼人回來更新），不會被忘掉。實測終局分布：
