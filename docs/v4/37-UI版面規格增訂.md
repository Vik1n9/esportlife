## 為什麼做這件事

§22 於 **v4.3.2 定案**（附錄 #53–#56），主線 S01–S22 共 39 站全部完成，
但**版面從未照 §22 做**。現行 UI 是 S03（進入點版面）與 S16（設施制訓練選單）
逐站長出來的最小可玩版面：頂欄四格 ＋ 卡片流 ＋ 底部決策槽 ＋ 單一長捲面板。

缺口盤點（七項）：

| §22 要求 | 現況 |
| --- | --- |
| 22.1 標題列「年月・階段 ｜ 距下階段倒數」 | 只有年份數字，無階段、無倒數 |
| 22.1 體力條常駐（第二列） | 只在選手資料面板裡 |
| 22.1 賽區 ｜ 隊伍名 ｜ 戰績排名 | 只有隊伍名 |
| 22.1 生涯任務指示列 | 完全沒有 |
| 22.1／22.5 屬性條常駐兩行 | 只在屬性點分配那幾秒出現 |
| 22.1「決策不提供技能讀數」 | ⚠ **現行違規**：狀態帶印本位置核心技能值（`src/ui/board.js`） |
| **22.2 卡牌覆寫** | ⚠ **整條未實作**：所有 `choice` beat 一律送底部決策槽（`src/ui/runner.js`） |
| 22.3 四 tab | 單一長捲抽屜；賽程／生涯兩個 tab 的內容**完全沒有出口** |

這些是 S38–S42 的輸入，不定案後面五站無法開工。

## 範圍

### 要做

**1. §22 增訂**（規格書）

- **22.1**：骨架線框細化到可施工粒度；明訂體力條常駐、屬性條帶蓄力第二刻度、
  屬性條緊貼決策槽、賽事五拍必須成組呈現、狀態帶不得出現任何技能值；
  新增日誌檢視控制（分類篩選＋年度跳轉）。
- **22.2**：三模式定案不動，補「為什麼分兩處」的理由、實作落點（`choice` beat 帶
  `slot`，由發射端指定）與線框；新增 **22.2.1 決策槽版面不變式**。
- **22.3**：內容不動，補線框並明訂「四 tab 是並列檢視入口，不是單一長捲」。
- **22.4**：**一字不動**。
- **22.5**：屬性條補蓄力讀數；明訂體力條常駐於狀態帶第二列。
- **22.6（新增）**：寬螢幕版面。三條不變式。

**2. `DESIGN.md` 同步**：Layout 斷點段＋五個新元件規格。色票／字型／幾何不動。

**3. 壬組登記**：`docs/v4/README.md` 新增壬組 S37–S42、六份站說明書、
`next-station.mjs` 驗證。

**4. 版號**：四份手抄本同步 v4.6.1（Z 級，使用者拍板）。

### 不要做

- **不推翻 §22.1「基準版面＝手機豎屏」**——寬螢幕是加一層，不是換一套。
- **不動 §22.4 資訊公開性**——它已定案且無實作偏差。
- **不改視覺語言**：`DESIGN.md` 的色票、字型、圓角尺度、平面無陰影原則全部照舊
  （使用者拍板「保留並延伸」）。
- **不引入建置工具**：維持純前端零建置 ESM。
- **不寫程式**。純文件站——除版號四份手抄本外，`src/` 與 `tests/` 不動。

## 交接筆記

2026-08-16 完成。純文件站：規格書 §22 增訂（22.1／22.2／22.2.1／22.3／22.5／
**新增 22.6**）、`DESIGN.md` 斷點與元件、壬組六站登記；版號升 **v4.6.1**
（Z 級：變動集中在 §22 一章，使用者拍板）。**除版號四份手抄本外程式與測試未動**，
`npm test` 基線不變。

**定案清單（每條的消費站見下）**：

1. **§22.2 是整條漏掉的，不是樣式偏好**（→ S39）。規格早就寫明卡牌選項要接在
   卡片下方、備賽戰術回決策槽，現行實作全部送底部。⚠ S39 注意：分流由**發射端**
   指定 `slot`，不要讓 UI 依 beat 內容猜——猜錯的那天沒有測試會紅。
2. **§0.5 防農檢驗是 UI 條款**（附錄 #76，→ S38／S39）。「決策所需資訊要多按一下
   才看得到，就是農」。體力常駐、蓄力刻度、選項就地、決策槽不跳動四條都由這條
   推導，不是偏好——實作站被要求砍範圍時，這四條是最後才能砍的。
3. **賽事五拍成組服務 §1.2**（→ S41）。五拍是規格點名的核心體驗「敘事儀式感」，
   散成五張同級卡片就讀不出是一場系列賽。這條不是美化，別當 nice-to-have 砍掉。
4. **蓄力刻度超出 §22.1 原文**（→ S38）。原文只寫「現值/潛力」，蓄力是本站新增。
   理由是它是玩家的成長貨幣（實況野球的経験点對應物），看不到就算不出「再幾點可升」。
5. **寬螢幕三條不變式**（附錄 #77，→ S42）。同類養成遊戲（賽馬娘、實況野球）
   皆為豎屏專用，**沒有可照抄的寬螢幕先例**——動線是豎屏調校出來的，寬螢幕沒有
   理由重推。S42 只做「攤開資訊」。

**⚠ 給 S38–S42 全組的警告**：`npm test` 的 19928 項**全部是引擎測試、完全不碰
DOM**。UI 改壞了測試不會紅。每站說明書的手動走查清單是唯一守門，不得跳過。
