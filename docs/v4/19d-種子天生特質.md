## 為什麼做這件事

V4 §1.4（v4.1 增訂）：種子除了潛力分佈與位置適性，**同時決定天生特質的有無與組合**。

| 天生特質數 | 機率 |
| --- | --- |
| 0 個 | 40% |
| 1 個 | 40% |
| 2 個 | 20% |

沒有 3 個以上的種子。同種子必定同組合。

這件事同時解掉三個既有問題：

1. **種子的份量太薄**。現在種子只給潛力與起始屬性，兩個 run 之間的差異玩家其實感覺
   不太到；天生特質是「一眼看得出不一樣」的那種差異。
2. **`鐵人` 取得率 0%**。§14.2 死配方規則點名的五個死素材裡，`鐵人` 是**完全沒有來源**
   的那一個。它是體質類，收進天生特質池就活了（V4 §14.1 已改判，S18 不必再為它補卡）。
3. **心理六維的開局全是 50 附近**。§9.1 的 `mentalBias` 讓帶天生特質的種子開局就偏，
   六維的分布拉得開一點。

## 範圍

### 要做

**必讀規格**：V4 §1.4（機率與抽取順序）、§9.1（`mentalBias` 與初始值對齊）、
§14.1 天生特質池那一節（只收人格／體質類、必須指派素材池）。

**1. 天生特質池（`src/data/innate.js`，新檔）**

- **只收基礎人格／體質類**。名稱暫定：天生抗壓、玻璃體質、天生領袖……
  **不含競技表現類**——「天生會打團」推不出來，那是 §0.5 直覺檢驗要擋的。
- 建議 8～12 個條目。太少的話 60% 的種子會反覆撞到同幾個。
- 每一個都要有：
  - **副作用**（§13.1／13.2 的分級，S19a 的規則）。天生特質是白拿的，所以副作用
    不能省——`玻璃體質` 本身就是一個純副作用的條目，那是刻意的
  - **`mentalBias {維度, 方向}`**（§9.1），體質類可以沒有
  - **素材池指派**：人格／媒體池 或 競技表現池。**沒有指派就是死路檢驗沒過**

**2. `鐵人` 收進池裡**

它已經在 `src/data/traits.js` 的 `BASE_TRAITS` 裡（效果都寫好了），也已經在 §14.2 的
競技表現池。這一站要做的是**給它一條天生來源**，不是重寫它。

**3. `createState` 的抽取**

V4 §1.4 把 `birth` 流的順序寫死了：

```
潛力分佈 → 起始屬性 → 天生特質 → 心理六維 → fame → 英雄池 → 業餘隊伍
```

**天生特質插在起始屬性之後、心理六維之前**——因為 §9.1 的 `mentalBias` 要先知道抽到
了什麼才能決定怎麼抽心理。

> ⚠ 這次插入會位移後面每一次取數，**所有既有種子的心理／fame／初始英雄池都會改變**。
> V4 本來就會 bump `SAVE_VERSION`，可以接受。但規格書寫明這是最後一次——之後要加出生期
> 擲骰一律接在最後面。

**4. `mentalBias` 的抽法（§9.1）**

- 被指定的維度：改抽 +6～+10（正向）或 −10～−6（負向），不再對稱
- 未指定的維度：維持原本的 ±10 jitter
- 0 個天生特質的種子（40%）：六維全部照舊，行為與 v4.0 相同

**5. 重量持有率**

天生特質進了通用池，**稀有與史詩的持有率會往上跑**。跑 160 段，量：

- 稀有 ≥1、史詩 ≥1、傳說 ≥1 的持有率（§14.2 目標表）
- 天生特質數的實際分布（應該收斂到 40/40/20）
- 六維的終局分布（S12 量到 `comp` 65／`conf` 66／`trust` 38、其餘三維貼在 50——
  看這一站有沒有把死維度拉起來一點）

**§14.2 的稀有目標值 50–60% 若被頂破，不要在這一站改配方**——把量到的數字寫進交接
筆記，S19c 統一重訂。

### 不要做

- **不要收競技表現類的天生特質**
- **不要讓天生特質可以在遊戲中取得**。§1.4：除了重選種子沒有別的管道
- **不要動 §14.2 的配方表**（S19c）
- **不要改既有 `BASE_TRAITS` 的效果**。`鐵人` 只是多一條來源
- 不要做 3 個以上天生特質的種子

## 規則與不變式

- S07 不變式全綠

### 抽取機制（§1.4）

出生流重排為規格書寫死的順序：潛力分佈 → 起始屬性 → **天生特質** → 心理六維 → fame → 英雄池 → 業餘隊伍 → 生命週期參數。**業餘隊伍從心理六維前移到英雄池後**（原本就不符合 §1.4，這次順便對齊）。天生特質 0/1/2 個（40/40/20%），`birth.sample` 均勻無放回，同種子必定同組合。`mentalBias` 指定維度改抽有向區間（正向 +6～+10／負向 −10～−6），未指定維持 ±10 jitter；0 個天生特質的種子六維行為與 v4.0 相同（統計均值 50）。

⚠ **這是 §1.4 寫明的最後一次出生流插隊**——之後要加出生期擲骰一律接在生命週期參數（最後）之後。

### 給 S19c 的數字

傳說 10.0% 距離 §14.2 目標 28–35% 很遠，但這是「舊配方時代」的既有差距（S19a 就 13.1%），**不是本站造成**——天生特質只有 0.8 條/種子，傳說合成樹沒吃到多少。稀有 53.8% 在目標內，天生特質沒有把它頂破（§14.2 擔心的情況沒發生）。史詩 38.8% 低於 55–65%——S19c 重訂配方時要優先查史詩素材池，不是稀有。

### 測試位移的連帶處理（重要）

出生流插隊 + 業餘隊伍重排會位移所有既有種子的天賦（心理／fame／英雄池／lifecycle），三處測試翻紅，已修：

1. **`tests/regression/invariants.mjs` §9.2 精確倍率**：`perform-probe` 抽到天生抗壓（mental_drive −4），`mentalMod` 疊進特質效果讓「恰 1.15」失效。修：`probe()` 清空 `state.traits`——純心理函數測試要乾淨狀態。
2. **`tests/kernel/stamina.mjs`**：`inj-old` 抽到鐵人（injuryRate cap 10%）、`pw-hi/pw-lo` 出生流不同。修：`fresh()` 清天生特質；體力對照組固定 attr/mental 全 50（場景只比體力）。
3. **`tests/phases/market.mjs` 青訓場景**：`academy-only` 一年業餘成長後 JG 評價跨過一隊門檻 56（CEILING_FLOOR 軟底讓 attr 50 必然漲破，舊隨機流綠是巧合）。修：心理/生命週期固定成中性值，斷言改「簽約選項不超過當下 rating」（一隊選項 ⇔ rating ≥ 56）＋簽下後階段與選項一致——保留防騙人精神，對出生流免疫。

⚠ 這個教訓要帶給後面各站：**用固定 seed + 覆寫 attr/potential 構造場景的測試，沒覆寫的 lifecycle／mental 是隱性輸入**，出生流一動就翻。場景要嘛固定所有出生流敏感輸入，要嘛斷言對它們免疫。
