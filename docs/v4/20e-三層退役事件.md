## 為什麼做這件事

規格 §18.2 定義退役走條件制三層結構（第一層特殊結局條件 → 第二層退役選項 →
第三層結局結算）。S18 說明書 7b（`18-事件卡擴充.md:149`）要求「由本站寫成特殊
事件卡」，但 S18 四批交接**全部**寫「刻意沒做：引擎無消費端」
（同檔 355／416／448／497／537 行）——於是**內容站等引擎、引擎站等內容，
兩邊都沒做**。這是 `20b` 審查列的 A1。

實測現況：

- `src/data/events.js` 86 張卡 `kind` 只有 `normal` 79／`patch` 3／`indulgent` 3／
  `romance` 1，**`special` 0 張**，五種特殊結局的卡 0 張。
  （`events.js:994` 有一張 `retire_thought`「退役念頭」，但那是 `kind:'normal'`、
  `slot:['regular','offseason']` 的普通月卡，不是 §18.2 的結局，也不在退役時觸發。）
- `src/engine/retire.js` **全文 12 行**，只有 `RetireSignal` 與一個 throw
  （`export const retire = (reason) => { throw new RetireSignal(reason); }`），
  無任何條件制結局判定。
- 退役敘事只剩 `game.js:205-224` 的通用 `retirement()`——一張
  `card('bad','職業生涯結束', state.retireReason)`，然後依 `careerTier()` 分數
  給榮譽殿堂或生涯總結。**純分數驅動，零 §18.2 條件。**

§18.2 的市場淘汰制因此只做了一半：淘汰有（`transfer.js:400-411` 無報價 → 退役），
結局分層無。

## 範圍

### 要做

**1. 判定接在 `game.js:205 retirement()`**

`retire()` 是 **throw**，會穿過所有 generator——所以判定**不能**放在
`transfer.js` 的退役分支裡，那裡 throw 之後的程式碼跑不到（`20b` 的 D3）。

`retirement()` 在 `careerFlow` 的 catch 之後執行（`game.js:63-77`）、已經拿得到
`g` 可以 yield beat，**9 個 `retire()` 呼叫點（`transfer.js:55, 196, 207, 315,
330, 340, 407, 410, 420`）一個都不必動**。

**2. 五張第一層特殊結局卡 ＋ 第二層選項**

第一層（§18.2）：王朝基石／冠軍謝幕／不屈老將／流星劃過／無聲告別。
第二層：宣布退役（永遠出現）／最後一搏／轉身離開／轉型教練。

建議另開 `src/data/retireCards.js` 而非塞進 `EVENT_CARDS` 的 `slot` 過濾——
`slot` 的語意假設月回合脈絡，`currentSlots()`（`eventTrigger.js:56`）產不出
退役時段（見 S20c 的 N7）。

**3. 五條結局條件寫成可求值謂詞**

⚠ **兩條缺謂詞**：「最後一季奪得世界賽冠軍」與「生涯無國際賽出場」。
`intlAppearances` 在 state 上，但**不在** `conditions.js` 的謂詞註冊表裡。

⚠ 規格 §18.2 有一條 v4.3.1 註記：「以下條件表僅供敘事參考，待特質與事件經編輯器
完成後再行重寫與校準」。**編輯器已完工**（S18a／S18b），本站定案並回寫規格。

可直接用的既有查詢：`longestTenure`（`ledger.js:32`，王朝基石的「同隊 ≥ 8 年」）、
`splitTitles`（`conditions.js:52`）、`peakRating`、`age`、教練評價。

**4. 第三層結算與既有結算協調**

`retirement()` 現在**無條件** yield 榮譽殿堂／生涯總結卡（`game.js:216-221`）。
特殊結局要插在它**之前**，且第三層敘事要觸發 §15.5 生涯傳記
（`buildBiography` 已存在，由 `summary.js:57` 消費）。

### 不要做

- **不要改 `retire.js` 的 throw 語意**——9 個呼叫點會全部受影響。
- 不要順手補事件卡條件（S20f）。
- 不要在這一站調退役相關的市場門檻（`FLOOR_RATING`、位置需求門檻等已由 S20d 定）。
- 不要為了湊條件而新增沒有出處的追蹤欄位。
