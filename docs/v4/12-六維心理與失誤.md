# S12 · 六維心理 ＋ 聲量層 ＋ 失誤系統

狀態：未開始
前置：S11
預估：1 session
推理難度：**高**
建議模型：Opus 5（`claude-opus-5`）
理由：心理是「放大器不是決定器」——這句話的實作邊界很窄，係數大一點就變成心理決定
一切、小一點就變成裝飾。而且失誤系統要讓「因隱藏、果可見」成立，玩家才推測得出來。
降級的風險是做出一個數字上存在、玩法上感覺不到的系統。

## 為什麼做這件事

V4 §9 用競技心理六維取代現行的 nerve/chem/ego/fame/rep。這兩組**不是同一條軸**：

| 現行（社交／聲量） | V4（競技心理） |
| --- | --- |
| `nerve` 大心臟、`chem` 隊友默契、`ego` 自我、`fame` 知名度、`rep` 風評 | `comp` 抗壓、`conf` 自信、`drive` 動機、`disc` 紀律、`trust` 信任、`resl` 韌性 |

V4 §9 只定義了新的六維，沒說薪資談判、轉會、切割改讀什麼——**已定案**
（見 `docs/v4/README.md`）：

- 薪資／試訓／續約／FA 讀 §10.2 教練評價（S11 已完成）
- `fame`（聲量）**保留為獨立層**
- `chem`（隊友默契）併入 `trust`
- `ego`（自我）不留維度，改由特質副作用承擔放大器角色
- `rep`（風評）不留維度，切割判定改讀教練評價＋特質副作用

核心分離（V4 §2）：**屬性決定技能「數值」，心理決定技能「發揮穩定度」。**
同一個 72 的會戰技能，抗壓高的人大賽發揮得出來，抗壓低的人會失常。

## 範圍

### 要做

**必讀規格**：V4 §9（隱藏心理素質，含 §9.2 成功率結算與 §9.3 失誤系統）、§2（三層
能力結構）、§10.2（教練評價的心理修正項）。

**1. `src/data/mental.js` 換成六維**

- `MENTAL_KEYS` → `['comp','conf','drive','disc','trust','resl']`
- 起始值約 50，種子天賦微調 ±10（§9.1）
- **`MENTAL_TIERS` 的處理要想清楚**：現行面板會顯示粗略標籤（「大場面型」「容易緊張」）。
  V4 §9.1 說「玩家不可見，僅從文本與事件結果推測」——所以**不該有標籤**。
  把標籤機制留給 `fame`（聲量）用

**2. 新增 `src/data/reputation.js`（聲量層）**

`fame` 從 mental 拆出來獨立。它是可見的、有分級標籤的、續約加薪與代言事件會讀的。
現行 `MENTAL_TIERS.fame` 的五級標籤（全民認識／圈內名人／有點知名度／小有耳聞／
沒沒無聞）直接搬過來。

**3. 新增 `src/engine/psych.js`**

V4 §9.2 的發揮公式：

```
技能發揮 = 技能值 × (0.85 + 0.30 × 心理修正值)
心理修正值 = Σ(主導心理維度 × 權重) 正規化到 0–1
```

心理 50 為基準（修正 ≈ 1.0），低於打折、高於加成。**係數 0.85／0.30 是規格書給的，
不要自己改**——那組數字定義了「放大器不是決定器」的邊界（極端心理只造成 ±15% 的
發揮差距）。

十二技能各自的「主導心理維度與權重」映射表 V4 §21.3 列為待細化。**S08 應該已經補上**，
若沒有，停下來寫進交接筆記，不要自己發明。

**4. V4 §9.3 失誤系統**

```
失誤率 = 基礎失誤率
       + 受迫項：f(抗壓低) × 壓力係數（大賽/生死戰/被針對時放大）
       + 非受迫項：f(紀律低) + f(自信過高)
失誤結果 → 反映在可見數據（陣亡、關鍵技能失手、會戰先倒）
```

設計要點：**因（心理）隱藏，果（陣亡、失手）可見**。玩家從數據推測心理，這是隱藏
探索循環的來源。所以失誤一定要**進 `season.js` 的可見數據**（陣亡數、關鍵局表現），
不能只是一個內部數字。

注意「自信**過高**」也是失誤來源（過自信→貪）——這是雙向的，不是越高越好。

**5. 接上 S11 留的心理修正接口**

`src/engine/attributes.js` 的 `TODO(S12)`：教練評價的心理修正項。
V4 §10.2 的意思是「教練看得出的態度與大賽心態」，所以吃的應該是 `drive`／`disc`／
`comp` 那幾維，不是全部六維平均。

**6. `src/engine/mental.js` 與事件卡的介面**

- `applyMental(state, {...})` 的鍵換成六維 ＋ 聲量
- `driftMental` 的漂移規則依新維度重寫
- `chemBonus`（`kernel/strength.js` 用）改讀 `trust`

⚠ **事件卡與扮演卡會壞**。`src/data/events.js` 與 `src/data/roleplay.js` 現在寫的是
舊維度鍵。這一站**只做最小修補讓測試跑得動**（機械對映：nerve→comp、chem→trust、
fame→fame、ego/rep→暫時丟棄並標 `TODO(S20)`），內容重寫是 S19a／S20。

**7. 讓 S07 的「心理是放大器不是決定器」SKIP 生效**

確認心理極端值造成的發揮差距在有界範圍內（±15% 左右）。
